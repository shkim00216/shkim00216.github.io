# #스크롤

## [스크롤 감지]

```javascript
scrollTo({ top: 50 }); /* 스크롤 맨 위에서 50만큼 떨어뜨려줘 */

scrollTo({ top: 0, behavior: "smooth" }); /* 스크롤 맨 위로 부드럽게 올려줘 */

scrollBy({ top: -500 }); /* 현재 위치에서 500만큼 올려줘 */
```

### 1. 윈도우 스크롤

<!-- CSS-JS/class-js/section03/03-01/01-scroll1-window.html 참고 -->

- 웹 브라우저 창 전체를 세로나 가로로 움직이는 것

```javascript
window.scrollTo({ top: 0 });
```

### 2. 엘리먼트 스크롤

<!-- CSS-JS/class-js/section03/03-01/01-scroll2-element.html 참고 -->

- 웹 페이지 안에 있는 특정 요소 자체를 스크롤하는 것
- 요소 내에서만 스크롤이 이루어지므로, 전체 페이지와는 별개로 동작

```javascript
document.getElementById("상자").scrollTo({ top: 0 });
```

## [스크롤과 주소창]

<!-- CSS-JS/class-js/section03/03-01/02-scroll-with-anchor1.html, 02-scroll-with-anchor2-detail.html 참고 -->

> **스크롤 앵커** : 특정 영역으로 자동 스크롤 하는 것

- 앵커는 URL의 끝에 `#` 기호 뒤에 위치
- 긴 웹 페이지에서 특정 섹션으로 직접 이동하고자 할 때 사용

```html
<!-- 특정 섹션 링크 -->
<a href="./02-scroll-with-anchor2-detail.html#나의연결고리2">상세보기</a>

<!-- 목차 링크 -->
<a href="#나의연결고리1">주제1</a>
<a href="#나의연결고리2">주제2</a>

<h1 id="나의연결고리1">주제1</h1>
<h1 id="나의연결고리2">주제2</h1>
```

## [이벤트 리스너와 스크롤 감지]

<!-- CSS-JS/class-js/section03/03-01/03-scroll-listener1-window.html, 03-scroll-listener2-element.html 참고 -->

> **이벤트 리스너(EventListener)** : 웹 페이지에서 사용자의 특정 행동(이벤트)을 감지하고, 그에 대한 반응을 정의하는 코드

```javascript
addEventListener("scroll", 기능); /* 스크롤 움직이면 기능 실행해줄게! */
```

- `scrollY` : 현재 페이지에서 수직으로 얼마나 스크롤 했는지를 픽셀 단위로 반환
- `scrollTop` : 선택한 요소의 수직 스크롤 위치를 픽셀 단위로 반환, 페이지 상단에서 스크롤 된 거리

# #이벤트 핸들러

<!-- precamp/class/03-javascript/07-signup.html,js 참고
 precamp/class/03-javascript/08-phone.html,js 참고 -->

> 함수는 `event`를 처리하거나 반응
> 이벤트 핸들러는 **이벤트 청취자**, 즉 위와 같은 **이벤트가 발생하는것을 감지하는 역할**

## [이벤트 핸들러의 종류]

### 1. onclick

```javascript
onclick = "자바스크립트함수();"; // 해당 태그를 클릭했을 때 자바스크립트 함수 실행
```

### 2. onchange

```javascript
onchange = "자바스크립트함수();"; // 해당 태그가 변경됐을 때 자바스크립트 함수 실행
```

### 3. onblur

```javascript
onblur = "자바스크립트함수();"; // 해당 태그에서 벗어났을 때 자바스크립트 함수 실행
```

### 💡 실무 예시

#### 1. 이벤트 핸들러 언제 사용하는지

- 버튼을 눌렀을 때 함수를 실행해야 한다거나 인풋창이 변할 때 함수를 실행해야 하는 등 **적절한 시기에 함수를 실행해야 할 때 사용**

# #이벤트 버블링

> **이벤트 버블링(Event Bubbling)** : 부모 위에 올려진 자식을 클릭하면 클릭 이벤트가 자식 아래의 부모까지 꾸욱 눌리는 것

```html
<form onclick="alert(form)">
  <div onclick="alert(div)">
    <p onclick="alert(p)">P</p>
  </div>
</form>
<!-- p→div→form 순서로 3개의 경고창이 나타남 -->
```

## [preventDefault]

<!-- CSS-JS/class-js/section03/03-02/01-event-bubbling-prevent-default1.html, 01-event-bubbling-prevent-default2-detail.html 참고 -->

> **preventDefault** : 웹 개발에서 자바스크립트를 사용해 이벤트가 기본적으로 수행하는 동작을 막을 때 사용되는 함수

```javascript
const 클릭기능 = (event) => {
  event.preventDefault();

  alert("클릭 하셨군요!");
};
```

```html
<a href="https://naver.com">
  <button onclick="클릭기능(event)">클릭</button>
</a>
```

- 원하는 동작을 수행하면서 불필요한 페이지 이동을 방지할 수 있음
- 원래대로 제공되는 기본 기능일 경우만 사용 가능

## [stopPropagation]

<!-- CSS-JS/class-js/section03/03-02/02-event-bubbling-stop-propagation.html 참고 -->

> **stopPropagation** : 이벤트가 부모 요소로 전파되는 것을 막는 함수

```javascript
const 부모클릭 = () => {
  alert("이것은 클릭되지 않습니다.");
};

const 자식클릭 = (event) => {
  event.stopPropagation(); // 부모태그로 클릭이벤트 전파(Propagation)를 중단(Stop)함 => 부모의 onclick 실행막음
  alert("클릭 하셨군요!");
};
```

```html
<div onclick="부모클릭()">
  <button onclick="자식클릭(event)">클릭</button>
</div>
```

- 부모가 a와 같은 기본 기능이 아닐 때 `stopPropagation`을 사용

# #이벤트 캡처링

<!-- CSS-JS/class-js/section03/03-02/03-event-capturing.html 참고 -->

> 상위에서 하위로 이벤트가 전파되는 단계

- `window.addEventListener`에 `{capture: true}` 옵션을 추가하여 이벤트 캡처링 활성화

### ⭐️ 실무 사용 팁

- **로그인체크기능** : 이벤트 캡처링을 통해 최상위 요소에서 클릭 이벤트를 감지하여 로그인 확인을 수행

```javascript
const JS_로그인체크기능 = (event) => {
  event.stopPropagation();

  const 비밀번호 = prompt("로그인 후 이용해 주세요.");

  if (비밀번호 === "1234") {
    alert("민지님 반갑습니다. 즐거운 여행 되세요~");
    window.removeEventListener("click", JS_로그인체크기능, { capture: true });
  } else {
    alert("로그인에 실패하였습니다. 다시 시도해 주세요.");
  }
};

window.addEventListener("click", JS_로그인체크기능, { capture: true });
```
