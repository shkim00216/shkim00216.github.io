# #트랜지션

<!-- CSS-JS/class-css/section02/02-01/01-transition.html 참고 -->

> **transition** : 처음 모습에서 마지막 모습으로 변하는 애니메이션

## 1. transition-property

> 어떤 속성(property)에 transition을 적용할 것인지

```css
transition-property: color, trasform;
```

## 2. transition-duration

> transition에 걸리는 시간

```css
transition-duration: 0.2s;
```

- `duration`은 초(s), 혹은 밀리초(ms) 단위로 지정이 가능

## 3. transition-timing-function

> transition의 속도 패턴

```css
transition-duration: ease-in-out | linear | ease | ease-in | ease-out;
```

- `ease-in-out` : 천천히 시작했다가, 정상 속도가 됐다가, 빠르게 끝남
- `linear` : 일정한 속도로 변화함
- `ease` : 시작할때는 빨라지다 느려짐
- `ease-in` : 천천히 시작했다가 속도를 높여 끝남
- `ease-out` : 빠른 속도로 시작했다가, 천천히 끝남

📌 [효과 확인 링크](https://codepen.io/Joogumi/full/eYMgrKO)

## 4. transition-delay

> transition 요청을 받은 후 실제로 실행되기까지 기다려야 하는 시간의 양

```css
transition-delay: 2s;
```

## [transition 속성 한번에 적어주기!]

```css
transition: color 0.4s ease-in-out 1s;
```

# #트랜스폼

<!-- CSS-JS/class-css/section02/02-01/02-transform1.html 참고 -->
<!-- CSS-JS/class-css/section02/02-01/02-transform2-with-transition.html 참고 -->

> **transform** : 대상이 되는 요소에 이동, 회전 확대/축소, 비틀기 등의 변형 효과를 줌

⭐️ 바꾸기 위한 **축**이 중요!

## 1. translate(x, y)

> 요소의 좌표를 움직일 수 있음

```css
/* 대상 요소를 X축으로 20px 만큼, Y축으로 25% 만큼 움직이겠다 */
transform: translate(20px, 25%);
```

❗️ 소괄호 안에 한개의 값만 입력된 경우에는 두 영역에 동일한 값이 입력된 것으로 간주

## 2. translateX(n) / translateX(n)

> 요소를 X좌표 or Y좌표를 기준으로 n만큼 움직일 수 있음

```css
transform: translateX(20px);
```

## 3. scale(x, y)

> 각 축 방향으로 x, y만큼 요소를 축소 혹은 확대

```css
/* 배수로 측정 */
transform: scale(0.75, 1.1);
```

## 4. scaleX(n) / scaleY(n)

> x or y축 방향으로 n만큼 요소를 축소 혹은 확대

```css
transform: scaleY(1.1);
```

## 5. skew(x, y)

> 요소를 기울여 마름모꼴처럼 만들어 줌

```css
transform: skew(15deg, 10deg);
```

## 6. skewX(n) / skewY(n)

> 요소를 X or Y축으로 n도 만큼 기울여 줌

```css
transform: skewX(15deg);
```

## 7. rotate(n)

> 요소를 n만큼 회전

```css
transform: rotate(45deg);
```

## 8. rotateX(n) / rotateY(n) / rotateZ(n)

> 축을 기준으로 요소가 회전

- `rotateX(n)`: X축을 기준으로 위 ⇒ 아래 방향으로 돌려서 뒤집기
- `rotateY(n)`: Y축을 기준으로 좌 ⇒ 우 방향으로 돌려서 뒤집기
- `rotateZ(n)`(기본값): Z축을 기준으로 돌려서 뒤집기

# #애니메이션

<!-- CSS-JS/class-css/section02/02-01/03-animation.html 참고 -->

## [@keyframes]

> 애니메이션의 각 단계를 정의하는 역할, 애니메이션의 시작 상태부터 끝 상태까지 요소의 스타일이 어떻게 변할지를 지정

```css
@keyframes 애니메이션_이름 {
  from {
    /* 애니메이션 시작 시의 스타일 /
	}
	
	to {
		/ 애니메이션 종료 시의 스타일 */
  }
}
```

- `from` : 애니메이션의 시작 시점, 초기 상태의 스타일을 정의
- `to` : 애니메이션의 끝 시점, 최종 상태의 스타일을 정의

## [@keyframes 에 여러 단계 추가하기]

```css
@keyframes 이동및색변경 {
  0% {
    background-color: red;
    transform: translateX(0);
  }
  50% {
    background-color: yellow;
    transform: translateX(100px);
  }
  100% {
    background-color: green;
    transform: translateX(200px);
  }
}
```

- `0%` : 애니메이션의 시작점(0%)
- `50%` : 애니메이션이 절반(50%)
- `100%` : 애니메이션이 끝날 때(100%)

## [animation 관련 속성들]

- `animation-name` : 어떠한 keyframes를 요소에 적용할 것인지 지정
- `animation-duration` : 애니메이션을 한 번 재생하는데 걸리는 시간을 설정
- `animation-direction` : 애니메이션 재생 방향을 정의(정방향/역방향)
  - `normal` : 정방향
  - `reverse` : 역방향
  - `alternate` : 정방향으로 재생(단, 정방향/역방향을 번갈아 재생)
  - `alternate-reverse` : 역방향으로 재생(단, 역방향/정방향을 번갈아 재생)
- `animation-iteration-count` : 애니메이션 재생 횟수를 정의
- `animation-timing-function` : 애니메이션 재생 패턴을 정의
- `animation-delay` : 애니메이션 시작을 얼마나 지연할 지 설정

```css
/* 애니메이션 단축속성 */
animation: moveRight 0.4s linear 1s infinite alternate;
```

## [transition vs animation]

|             | transition                                                    | animation                                                                      |
| :---------: | :------------------------------------------------------------ | :----------------------------------------------------------------------------- |
|  자동 시작  | 상태 변화(예: `hover`, `focus`, `active` 등)가 있을 때만 동작 | 페이지가 로드되면 자동으로 시작, 별도의 이벤트가 필요 없음                     |
| 반복 가능성 | 이벤트가 발생할 때마다 한 번씩 실행                           | `animation-iteration-count` 속성을 사용하여 반복 횟수를 설정, 무한 반복도 가능 |
| @keyframes  | 중간 단계의 제어는 불가능                                     | `@keyframes`를 사용하여 중간 상태 제어 가능, 복잡한 애니메이션 만들 수 있음    |

## 1. 토스트(Toast)

> 화면의 특정 위치(주로 화면의 오른쪽 하단 혹은 중앙)에 일시적으로 표시되는 메시지

- 일반적으로 사용자에게 정보, 알림, 또는 상태 업데이트를 전달하는데 사용
- 주로 성공적인 작업, 오류 메시지, 알림 등을 유저에게 간단히 전달할 때 사용

## 2. 스낵바(Snackbar)

> 화면 하단에 나타나는 알림 메시지의 일종으로, 특정 작업에 대한 확인 메시지를 제공

- 스낵바는 사용자가 수행한 작업에 대한 피드백을 제공하는데 초점
- 실행 취소 버튼 등으로 사용자가 추가 작업을 수행할 수 있어 특정 작업에 대한 피드백을 제공하고, 추가적인 행동을 유도할 때도 사용

### 💡 토스트와 스낵바 차이점

- 토스트는 단순 메시지이며, 스낵바는 클릭 및 드래그 기능이 가능

## 3. 로딩(Loading)

> 사용자가 요청한 작업이 진행중임을 알리는 역할

- `스피너(spinner)`, `바(bar)`, `점(dot)` 그리고 애니메이션된 아이콘 등의 형태로 제공
- 사용자가 기다리는 동안 느끼는 지루함을 덜어주고, 애플리케이션이 멈춘게 아니라 정상적으로 작동하고 있다는 신뢰감을 줌

## 4. 스켈레톤 애니메이션(Skeleton Animation)

> 로딩 상태를 시각적으로 나타내기 위해 사용되는 기법

- 주로 컨텐츠가 로드 되는 동안 사용자에게 무엇이 표시될 것인지에 대한 힌트를 제공하기 위해 사용
- 일반적으로 회색 또는 밝은 색상의 빈 사각형이나, 선 형태로 구성
