## 스토리지

<!-- CSS-JS/class-js/section02/02-01/01-localstorage-and-sessionstorage.html 참고 -->

### 로컬스토리지(LocalStorage)

<mark>데이터를 **도메인 단위**로 저장</mark>

- **비휘발성 메모리**로 저장된 데이터가 브라우저, PC를 종료하더라도 그대로 남아있음
- 반영구적으로 직접 데이터를 삭제할 때까지 존재

```javascript
localStorage.setItem("data-key", "data-value"); /* 객체처럼 저장 */
localStorage.getItem("data-key");
```

### 세션스토리지(SessionStorage)

<mark>데이터를 **세션 단위**로 저장</mark>

- 사용자가 페이지에 접속하는 순간부터 접속이 끊어지는 순간까지 저장
- 해당 페이지와 접속이 끊어지거나 브라우저를 종료하게 되면 해당하는 세션 저장소의 데이터를 영구히 삭제, **휘발성 메모리**

```javascript
sessionStorage.setItem("data-key", "data-value");
```

### 쿠키

만료일까지 존재

```javascript
document.cookie = "data-key = data-value";
```

## JSON

<!-- CSS-JS/class-js/section02/02-01/02-localstoarge-with-json.html 참고 -->

> **JSON(JavaScript Object Notation)** : 데이터를 저장하고 전송하기 위한 경량 데이터 형식, 주로 웹 애플리케이션에서 서버와 클라이언트 간의 데이터를 교환할 때 사용

⚠️ 숫자든 객체든 모두 문자열로 저장되어 불러오기 어려움 -> 변환 필요

### 객체를 문자열로 바꾸어 로컬스토리지에 저장(JSON.stringify)

```javascript
const JS_과일담기기능 = () => {
  const 과일담는통 = {
    사과: 3,
    바나나: 2,
    딸기: 10,
  };
  const 문자열로바뀐객체 = JSON.stringify(과일담는통);
  localStorage.setItem("과일바구니", 문자열로바뀐객체);
};
```

### 로컬스토리지에서 객체 불러오기(JSON.parse)

```javascript
const JS_과일꺼내기기능 = () => {
  const 과일바구니문자열 = localStorage.getItem("과일바구니");
  const 과일바구니객체 = JSON.parse(과일바구니문자열);
  console.log(과일바구니객체);
};
```

## 라우팅

<!-- CSS-JS/class-js/section02/02-01/03-routing1.html 참고 -->

> **라우팅(Routing)** : 사용자가 클릭하거나 특정 동작을 했을 때, 웹 애플리케이션에서 다른 페이지로 이동하는 방법

### 1. location.href

```javascript
const JS_게시글수정기능 = () => {
  alert("게시글이 수정되었습니다.");
  location.href = "./03-routing2-detail.html"; // 현재 페이지 위에 새로운 페이지를 올려놓음 => 뒤로가기하면 현재 페이지로 돌아올 수 있음
};
```

새로운 페이지가 현재 페이지 위에 열림, 따라서 사용자가 "뒤로 가기" 버튼을 클릭하면 이전 페이지로 돌아올 수 있음

### 2. location.replace

```javascript
const JS_결제하기기능 = () => {
  alert("결제가 완료되었습니다.");
  location.replace("./03-routing2-detail.html"); // 현재 페이지를 지우고, 새로운 페이지로 교체 => 뒤로가기해도 현재 페이지로 돌아올 수 없음
};
```

현재 페이지가 지워지고 새로운 페이지로 대체, 따라서 사용자가 "뒤로 가기" 버튼을 클릭해도 이전 페이지로 돌아올 수 없음

### 3. 링크를 사용한 라우팅

```html
<a href="./03-routing2-detail.html">상세보기</a>
```

### 4. 링크에 쿼리스트링을 사용한 라우팅

<abbr title="queryString">**쿼리스트링** : 주소를 통해 데이터 전달하는 방법</abbr>

```html
<a href="./03-routing3-detail-querystring.html?banana=15&apple=10"
  >데이터가지고 페이지이동하기</a
>
```

쿼리스트링을 사용하여 데이터를 URL에 포함해 다른 페이지로 전달할 수 있음

### 5. history.back()

직전에 방문했던 페이지로 이동

```html
<button onclick="history.back()">뒤로 가기</button>
```

## 내장함수

> 자주 사용되는 함수를 자바스크립트에 내장하여 편리하게 이용할 수 있도록 한 것

### 1. setTimeout

**시간 지연 함수**로 입력 시간이 만료된 후 함수나 지정한 코드를 실행

```javascript
setTimeout(func, time);
```

### 2. setInterval

**시간 반복 함수**로 입력한 시간마다 함수를 반복적으로 호출하거나 코드를 실행

```javascript
setInterval(func, time);
```

### 3. alert

메세지를 지정할 수 있는 **경고 대화 상자**를 띄움

```javascript
alert("이렇게 만드시면 경고창이 생겨요!");
```

⚠️ 시간 입력 시 ms(밀리세컨드) 단위로 입력

<mark>1초에 1000ms</mark>

### 시간지연함수와 시간반복함수의 종료

```javascript
// 시간지연함수 강제종료
const time = setTimeout(기능, 시간); // 시간지연함수를 임시로 변수/상수에 저장
clearTimeout(time); // 저장했던 시간지연함수를 종료

// 시간반복함수 강제종료
const time = setInterval(기능, 시간); // 시간반복함수를 임시로 변수/상수에 저장
clearInterval(time); // 저장했던 시간반복함수를 종료
```

- 각각의 종료 함수는 각자의 함수 안에서 사용할 수 있음
  - 즉, `clearInterval`은 `setInterval`안에서 사용할 수 있다는 뜻

## 데이터 타입

<!-- precamp/class/03-javascript/연습-05-variable-if.js 참고 -->

### 데이터 타입 종류

<abbr title="primitive">**원시타입(Primitive type)** : 불변성의 특징을 가짐</abbr>

1. `문자열(String)` : 문자열은 “” 안에 적어주며, 따옴표 안에 적힌 값들은 숫자여도 문자열로 취급
2. `숫자(Number)` : 숫자를 나타내는 자료형이며 모든 숫자를 실수로 처리 - <mark>**주의** 따옴표 없이 적어야 함</mark>
3. `불린(Booolean)` : true(참), false(거짓)으로 나타내는 자료형
4. `undefined` : 변수를 선언했지만 값이 할당되지 않았을 때 자바스크립트 엔진이 암묵적으로 초기화 하는 값
5. `null` : 의도적으로 값이 없음을 명시하기 위해 할당하는 값

```javascript
let name = "캠프"; // (문자열)
let number = 3; // (숫자열) ""를 쓰지 않아야 숫자
let fool = true; // ""를 쓰지 않아야 boolean
```

<abbr title="primitive">**참조타입(Reference type)** : 나머지 모든 타입, 참조타입 = 객체타입, 가변성의 특징을 가짐</abbr>

### 데이터 타입 확인 및 변경

`typeof` 명령을 이용하여 자료형을 확인

```javascript
typeof "name"; // "string"을 반환
typeof "nubmer"; // "number"을 반환
typeof "fool"; // "boolean"을 반환
```

데이터 타입 변경 가능

```javascript
Number("35"); // 문자 35를 숫자 35로 변경
String(24); // 숫자 24를 문자 "24"로 변경
String(true); // 불린 true를 문자 "true"로 변경
```

## 연산자

### 1. 산술연산자

> 산술연산자는 **더하기(+) , 빼기(-), 곱하기(\*), 나누기(/), 나머지(%)**와 같은 연산을 하는 기호를 의미

#### 문자타입의 연산

숫자 타입의 연산과 문자 타입의 연산 결과는 완전히 다름

```javascript
//숫자 타입 연산
89 + 54;
// 결과 : 140

// 문자 타입 연산
"89" + "54";
// 결과 : "8954"
```

- 숫자와 문자의 연산 결과는 문자열로 계산됨(`+`)
  - 다른 `-`, `*` 연산은 어느정도 유연성으로 숫자로 계산됨

</fieldset>

## 2. 비교연산자

> 비교연산자는 좌우의 두 값을 비교해야 할 때 사용하는 연산자이며, Boolean을 반환

- `===` : 같다
- `!==` : 같지 않다
- `<=` : 작거나 같다
- `>=` : 크거나 같다
- `>` : 크다
- `<` : 작다

<mark>등호의 순서는 중요함</mark>

#### ⚠️ 엄격한 동치연산자

- `==`, `!=`는 타입은 무시한채 값만 비교함(느슨한 동치연산자 - 실무 사용 X)
- `===`, `!==`는 데이터 타입과 값까지 같아야 `True`
- ⭐️ 실무에서는 엄격한 비교연산자만을 사용

### 3. 논리연산자

> 논리연산자는 **그리고(&&), 또는(\|\|), 부정(!)**을 나타내는 기호를 의미

- `&&` : 양쪽이 모두 True여야 True를 반환
- `||` : 한쪽만 True여도 True를 반환
- `!` : Boolean을 반전시킴

## 조건문

<!-- precamp/class/03-javascript/연습-05-variable-if.js 참고 -->
<!-- CSS-JS/class-js/section02/02-02/01-if-and-switch.html 참고 -->

> **조건문** : 작성한 조건이 참일 경우 지정한 코드를 수행하도록 하는 기능

### if…else

**핵심** : 시작점과 끝점이 존재
- 비교 연산자와 함께 쓰임
- 조건이 맞다면 `A` 실행, 아니라면 `B` 실행

```javascript
if(조건) {
  A 실행
} else {
  B 실행
}
```

- 조건1이 맞다면 `A` 실행, 아니면 조건2가 맞다면 `B` 실행, 아니면 조건3이 맞다면 `C` 실행, 모두 아니면 `D` 실행
- 조건문 개수 제한은 없음

```javascript
if(조건1) {
  A 실행
} else if(조건2) {
  B 실행
} else if(조건3) {
  C 실행
} else {
  D 실행
}
```

#### 삼항연산자(초간단 조건문)

```javascript
const 상자 = 1 + 1 === 2 ? "500원" : "0원";
```

### switch문

- 변수의 값을 평가하여 여러 경우 중 하나에 해당하는 코드 실행
- 특정 변수의 값에 따라 여러 분기 처리를 할 때 사용, 가독성이 좋고, 많은 경우를 처리할 때 사용
- `break문`을 이용해서 각 케이스의 종료를 명시적으로 관리
- ⚠️ 일치하는 것이 없다면, default 값 실행
- ⚠️ 일치하는 것이 있다면, 아래 코드들이 다 실행됨 -> `break` 필수!

```javascript
switch (변수) {
  case 조건1:
    // 조건1이 참이면 실행할 코드
    break;
  case 조건2:
    // 조건2이 참이면 실행할 코드
    break;
  default:
  // 어떤 값도 해당하지 않을 때 실행할 코드
}
```

## 반복문

<!-- precamp/class/03-javascript/연습-06-for.js 참고 -->

> 같은 행위를 반복하는 것

**핵심** : 몇 번 반복할 것인가

### For문 작성 방법

```javascript
for (초기식; 조건식; 증감문) {
  반복해서 실행할 내용
}

for (let i=0; i<5; i=i+1) {
  console.log("hello")
}
```

- 초기식 : 변수의 선언 `let 변수 = 0`
- 조건식 : 반복할 조건
- 증감식 : 변수의 증가 또는 감소 식 `i++`/`i--`

⚠️ 특정 조건 만족 시,  
조건식을 통한 정상 종료 이전에도 `종료(break)` 가능  
명령문을 실행하지 않고 다음 반복으로 `건너뛰기(continue)` 가능

### MAP

<abbr title="map">map : 배열 객체의 메서드, 배열의 각 요소에 주어진 함수를 호출하여 새로운 배열을 생성</abbr>

**원래 배열은 변경되지않고, 새로운 배열이 반환**

```javascript
const 친구들 = ["철수", "영희", "훈이"];
const 우리반 = 친구들.map((친구) => 친구 + "어린이");
// ["철수어린이", "영희어린이", "훈이어린이"]

/* 화살표 함수 -> 중괄호 생략 버전 */
const 우리반 = 친구들.map((친구) => {
  return 친구 + "어린이";
}); // 상황에 따라 생략 가능, return 값만 존재할 경우
```

#### ⚠️ map 사용 시 배열 구분 없이 태그만 필요한 경우

`함수명.join("")` 사용

```javascript
const 색깔들 = ["빨강", "노랑", "파랑"];
const 버튼HTML = 색깔들.map(
  (색깔) => `
  <button> &{색깔} </button>
`
);

document.getElementById("나의태그").innerHTML = 버튼HTML.join("");
```

```html
<!-- 결과 -->
<div id="나의태그">
  <button>빨강</button><button>노랑</button><button>파랑</button>
</div>
```

⭐️ 태그에 속성 추가도 가능!

### forEach

<abbr title="foreach">배열의 각 요소에 대해 주어진 함수를 호출하지만, 반환값은 없음</abbr>

```javascript
const 친구들 = ["철수", "영희", "훈이"];
친구들.forEach((el) => {
  console.log(el + "어린이");
});
// "철수어린이"
// "영희어린이"
```

### filter

<abbr title="filter">배열의 각 요소를 테스트하여 조건을 만족하는 요소만으로 구성된 새로운 배열을 생성하는데 사용</abbr>

```javascript
const 친구들 = ["철수", "영희", "훈이"];
const 남자애들 = 친구들.filter((el) => el !== "영희");
/* filter로 true와 false 반환 */

// ["철수", "훈이"]
```
