# #스토리지

<!-- CSS-JS/class-js/section02/02-01/01-localstorage-and-sessionstorage.html 참고 -->

## [로컬스토리지(LocalStorage)]

> 데이터를 **도메인 단위**로 저장

- **비휘발성 메모리**로 저장된 데이터가 브라우저, PC를 종료하더라도 그대로 남아있음
- 반영구적으로 직접 데이터를 삭제할 때까지 존재

```javascript
localStorage.setItem("data-key", "data-value"); /* 객체처럼 저장 */
localStorage.getItem("data-key");
```

## [세션스토리지(SessionStorage)]

> 데이터를 **세션 단위**로 저장

- 사용자가 페이지에 접속하는 순간부터 접속이 끊어지는 순간까지 저장
- 해당 페이지와 접속이 끊어지거나 브라우저를 종료하게 되면 해당하는 세션 저장소의 데이터를 영구히 삭제, **휘발성 메모리**

```javascript
sessionStorage.setItem("data-key", "data-value");
```

## [쿠키]

- 만료일까지 존재

```javascript
document.cookie = "data-key = data-value";
```

# #JSON

<!-- CSS-JS/class-js/section02/02-01/02-localstoarge-with-json.html 참고 -->

> **JSON(JavaScript Object Notation)** : 데이터를 저장하고 전송하기 위한 경량 데이터 형식, 주로 웹 애플리케이션에서 서버와 클라이언트 간의 데이터를 교환할 때 사용

❗️ 숫자든 객체든 모두 문자열로 저장되어 불러오기 어려움 -> 변환 필요

## [객체를 문자열로 바꾸어 로컬스토리지에 저장(JSON.stringify)]

```javascript
const JS_과일담기기능 = () => {
  const 과일담는통 = {
    사과: 3,
    바나나: 2,
    딸기: 10,
  };
  const 문자열로바뀐객체 = JSON.stringify(과일담는통);
  localStorage.setItem("과일바구니", 문자열로바뀐객체);
};
```

## [로컬스토리지에서 객체 불러오기(JSON.parse)]

```javascript
const JS_과일꺼내기기능 = () => {
  const 과일바구니문자열 = localStorage.getItem("과일바구니");
  const 과일바구니객체 = JSON.parse(과일바구니문자열);
  console.log(과일바구니객체);
};
```

# #라우팅

<!-- CSS-JS/class-js/section02/02-01/03-routing1.html 참고 -->
<!-- CSS-JS/class-js/section02/02-01/03-routing2-detail.html 참고 -->

> **라우팅(Routing)** : 사용자가 클릭하거나 특정 동작을 했을 때, 웹 애플리케이션에서 다른 페이지로 이동하는 방법

## 1. location.href

```javascript
const JS_게시글수정기능 = () => {
  alert("게시글이 수정되었습니다.");
  location.href = "./03-routing2-detail.html"; // 현재 페이지 위에 새로운 페이지를 올려놓음 => 뒤로가기하면 현재 페이지로 돌아올 수 있음
};
```

- 새로운 페이지가 현재 페이지 위에 열림, 따라서 사용자가 "뒤로 가기" 버튼을 클릭하면 이전 페이지로 돌아올 수 있음

## 2. location.replace

```javascript
const JS_결제하기기능 = () => {
  alert("결제가 완료되었습니다.");
  location.replace("./03-routing2-detail.html"); // 현재 페이지를 지우고, 새로운 페이지로 교체 => 뒤로가기해도 현재 페이지로 돌아올 수 없음
};
```

- 현재 페이지가 지워지고 새로운 페이지로 대체, 따라서 사용자가 "뒤로 가기" 버튼을 클릭해도 이전 페이지로 돌아올 수 없음

## 3. 링크를 사용한 라우팅

```html
<a href="./03-routing2-detail.html">상세보기</a>
```

## 4. 링크에 쿼리스트링을 사용한 라우팅

> **쿼리스트링** : 주소를 통해 데이터 전달하는 방법

```html
<a href="./03-routing3-detail-querystring.html?banana=15&apple=10"
  >데이터가지고 페이지이동하기</a
>
```

- 쿼리스트링을 사용하여 데이터를 URL에 포함해 다른 페이지로 전달할 수 있음

## 5. history.back()

- 직전에 방문했던 페이지로 이동

```html
<button onclick="history.back()">뒤로 가기</button>
```

# #내장함수

> 자주 사용되는 함수를 자바스크립트에 내장하여 편리하게 이용할 수 있도록 한 것

## 1. setTimeout

- **시간 지연 함수**로 입력 시간이 만료된 후 함수나 지정한 코드를 실행

```javascript
setTimeout(func, time);
```

## 2. setInterval

- **시간 반복 함수**로 입력한 시간마다 함수를 반복적으로 호출하거나 코드를 실행

```javascript
setInterval(func, time);
```

## 3. alert

- 메세지를 지정할 수 있는 **경고 대화 상자**를 띄움

```javascript
alert("이렇게 만드시면 경고창이 생겨요!");
```

❗️ 시간 입력 시 ms(밀리세컨드) 단위로 입력

- 1초에 1000ms

## [시간지연함수와 시간반복함수의 종료]

```javascript
// 시간지연함수 강제종료
const time = setTimeout(기능, 시간); // 시간지연함수를 임시로 변수/상수에 저장
clearTimeout(time); // 저장했던 시간지연함수를 종료

// 시간반복함수 강제종료
const time = setInterval(기능, 시간); // 시간반복함수를 임시로 변수/상수에 저장
clearInterval(time); // 저장했던 시간반복함수를 종료
```

- 각각의 종료 함수는 각자의 함수 안에서 사용할 수 있음
  - 즉, `clearInterval`은 `setInterval`안에서 사용할 수 있다는 뜻
