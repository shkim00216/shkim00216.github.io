## CSS란?

> **cascading style sheet** : HTML의 색, 크기, 정렬 등을 변경하여 꾸며주는 언어

```css
p {
  color: red;
}
/* 선택자(Selector)와 선언(Declaration)으로 구분됨 */
/* 선언은 다시 속성(property), 속성값(property value)의 구조 */
```

<ul>
  <li><b>선택자</b> : 어떤 HTML 요소를 선택해서 스타일을 적용할 것인지 지정</li>
  <li><b>선언</b> : 구체적으로 어떠한 스타일을 선택자에 적용할 것인지 지정</li>
  <br>
  <li><b>속성</b> : 적용하고자 하는 스타일의 종류</li>
  <li><b>속성값</b> : 해당 속성을 정확하게 어떤 값으로 지정할 것인지를 결정</li>
</ul>

## CSS 사용방법 3가지

### 1. html 태그에 입력하기

- `html`태그에 입력하면 유지 보수 측면에서 굉장히 비효율적

```html
<!-- 태그에 CSS 바로 적용하기 -->
<h1 style="color:red">철수</h1>
<h1 style="color:blue">영희</h1>
```

### 2. style 태그에 입력하기

- 유지보수 측면에서는 유리할 수 있지만 관심사 분리가 안됨

```html
<!-- Head 태그 안에 Style 태그로 작성하기 -->
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Style 태그에 입력하기</title>
    <style>
      * {
        margin: 0;
      } /* 전체 선택자 */
      h1 {
        color: red;
      } /* 태그 선택자 */
      #aaa {
        color: blue;
      } /* id 선택자 */
      .bbb {
        color: green;
      } /* class 선택자 */
    </style>
  </head>
</html>
```

### 3. css파일 분리

- **실무에서 가장 많이 사용**되며, 유지 보수에 유리
- 파일을 불러올때는 `link` 태그를 사용합니다.

```html
<!-- Head 태그 안에 link 태그로 별도로 작성된 css 파일 연결해서 작성하기 -->
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="stylesheet" href="./index.css" />
    <title>Link 태그로 CSS 파일 연결하기</title>
  </head>
  <body>
    <h1 id="aaa">Hello World!</h1>
    <div class="bbb">Hello World!</div>
  </body>
</html>
```

## CSS 선택자

선택자는 CSS에서 꾸밀 대상 즉, 속성을 줄 대상을 뜻함

1. `*` : 전체 선택자
2. `tag` : 태그 선택자
3. `.class` : 클래스선택자
4. `#id` : 아이디선택자
5. `선택자:가상상황` : 가상선택자

#### ⭐️ 선택자에는 tag ⇒ class ⇒ id 순으로 우선순위가 적용

## 박스모델

<!-- precamp/class/02-css/01-boxmodel.html 참고 -->

- `margin` : border를 기준으로 박스의 바깥 여백
- `border` : 박스의 기준이 되는 바깥 테두리 선
- `padding` : 박스의 안쪽 여백
- `contents` : 박스의 실질적인 내용 부분

<!-- CSS-JS/class-css/section01/01-01/02-box-sizing.html 참고 -->

### [박스모델 화면 표시 방법]

- `border-box` : border가 고정되고 contents 크기가 변함(박스가 고정)
- `content-box` : contents가 고정되고 border의 크기가 변함(박스가 커짐)

#### ⭐️ 바깥테두리(박스전체)를 고정시키는 border-box 사용을 권장

#### ⭐️ 컴포넌트란?

> 마치 레고블록과 같음

- **재사용성**: 한번 만든 컴포넌트는 여러 곳에서 다시 사용할 수 있음, 예) 한 번 만든 버튼을 다른 페이지에서도 사용할 수 있음
- **유지보수성**: 컴포넌트가 고장 나면 그 부분만 고치면 됨, 다른 부분에 영향을 주지 않으니까 쉽게 고칠 수 있음
- **가독성**: 컴포넌트가 각각의 역할을 명확하게 가지고 있어서, 어떤 역할을 하는지 이해하기 쉬움

## 정렬

<!-- CSS-JS/class-css/section01/01-02/01-flexbox.html 참고 -->

### 1. flex

- 여러태그를 하나로 묶어 정렬
- `flex`는 기준을 부모박스로 두고 움직이게 됨

```css
/* 부모박스 */
display: flex;

/* 행기준: row, 열기준: column */
flex-direction: row;
flex-direction: column;

/* flex-direction 기준 수평 방향으로 자식박스 정렬 */
justify-content: center;

/* flex-direction 기준  수직 방향으로 자식박스 정렬 */
align-items: center;
```

<!-- CSS-JS/class-css/section01/01-02/02-flexbox-wrap.html 참고 -->

#### [flex-wrap]

> `item`들의 줄바꿈을 허용할 것인지 말 것인지 결정

- `flex-wrap : nowrap` (기본값)
  - item의 줄바꿈을 허용하지 않음, 무조건 한줄
- `flex-wrap : wrap`
  - item의 가로 사이즈가 container의 가로 사이즈를 넘겼을 때, 자연스럽게 다음 줄로 넘어감

#### ⭐️ `item`이 두 줄 이상인 상태에서 정렬을 원하면, `align-content`라는 속성을 이용

#### [gap]

> 자식 요소들 사이의 간격을 지정해주는 속성

```css
.CSS_부모 {
  display: flex; /* flexbox 사용 */
  gap: 20px; /* 각 아이템 사이에 20px 간격을 줌 */
}
```

<!-- CSS-JS/class-css/section01/01-02/03-flexbox-column.html 참고 -->

#### 💡 flexbox 세로가 안되는 이유

- `flex-box`는 크기를 가진 공간 안에서만 작동하게 되므로, 높이를 설정해줘야 함

#### 💡 한 화면 사이즈에 맞추고 싶을 때

- `Viewport-Width(vw)` : 화면 가로 사이즈
- `Viewport-Heght(vh)` : 화면 세로 사이즈

### 2. position

- `flex`에 종속되지 않고, 박스를 개별적으로 위치

```css
/* 박스의 절대 위치 */
div {
  position: absolute;
  top: 0px;
  left: 0px;
}

/* 부모 박스 기준으로 상대위치 */
div {
  position: relative;
  top: 0px;
  left: 0px;
}

/* 화면을 기준으로한 절대 위치 */
div {
  position: fixed;
  bottom: 0px;
}
```
