# 자바스크립트

## #데이터 타입

### [데이터 타입 종류]

1. `문자열(String)` : 문자열은 “” 안에 적어주며, 따옴표 안에 적힌 값들은 숫자여도 문자열로 취급
2. `숫자(Number)` : 숫자를 나타내는 자료형이며 모든 숫자를 실수로 처리
   ❗️ **주의** 따옴표 없이 적어야 함 ❗️
3. `불린(Booolean)` : true(참), false(거짓)으로 나타내는 자료형
4. `undefined` : 변수를 선언했지만 값이 할당되지 않았을 때 자바스크립트 엔진이 암묵적으로 초기화 하는 값
5. `null` : 의도적으로 값이 없음을 명시하기 위해 할당하는 값

```javascript
let name = "캠프"; // (문자열)
let number = 3; // (숫자열) ""를 쓰지 않아야 숫자
let fool = true; // ""를 쓰지 않아야 boolean
```

### [데이터 타입 확인 및 변경]

- `typeof` 명령을 이용하여 자료형을 확인

```javascript
typeof "name"; // "string"을 반환
typeof "nubmer"; // "number"을 반환
typeof "fool"; // "boolean"을 반환
```

- 데이터 타입 변경 가능

```javascript
Number("35"); // 문자 35를 숫자 35로 변경
String(24); // 숫자 24를 문자 "24"로 변경
String(true); // 불린 true를 문자 "true"로 변경
```

## #연산자

### 1. 산술연산자

> 산술연산자는 `더하기(+) , 빼기(-), 곱하기(*), 나누기(/), 나머지(%)`와 같은 연산을 하는 기호를 의미

#### ❗️ 문자타입의 연산

- 숫자 타입의 연산과 문자 타입의 연산 결과는 완전히 다름

```javascript
//숫자 타입 연산
89 + 54;
// 결과 : 140

// 문자 타입 연산
"89" + "54";
// 결과 : "8954"
```

- 숫자와 문자의 연산 결과는 문자열로 계산됨(`+`)
  - 다른 `-`, `*` 연산은 어느정도 유연성으로 숫자로 계산됨

#### ⭐️ 실무 예제

#### 1. 나머지(%) 연산자 사용

- 게시판의 게시물에서 각 줄을 **홀/짝으로 구분**하고 색을 다르게 할 때 사용

### 2. 비교연산자

> 비교연산자는 좌우의 두 값을 비교해야 할 때 사용하는 연산자이며, `Boolean`을 반환

- `===` : 같다
- `!==` : 같지 않다
- `<=` : 작거나 같다
- `>=` : 크거나 같다
- `>` : 크다
- `<` : 작다

- 등호의 순서는 중요함

#### ❗️ 엄격한 동치연산자

- `==`, `!=`는 타입은 무시한채 값만 비교함(느슨한 동치연산자 - 실무 사용 X)
- `===`, `!==`는 데이터 타입과 값까지 같아야 True

### 3. 논리연산자

> 논리연산자는 `그리고(&&), 또는(||), 부정(!)`을 나타내는 기호를 의미

- `&&` : 양쪽이 모두 True여야 True를 반환
- `||` : 한쪽만 True여도 True를 반환
- `!` : Boolean을 반전시킴
