# #반응형 디자인

> 화면에 크기에 반응하여 변경되는 디자인

<!-- CSS-JS/class-css/section04/04-01/01-responsive-design.html 참고 -->

## [max-width]

- 어떤 요소의 최대 너비를 설정하는 속성

```css
width: 500px;
max-width: 400px;

/* 400px 이하로만 이미지가 보이게 됨 */
```

## [%]

- 요소의 크기, 위치, 패딩, 마진 등을 부모 요소에 상대적으로 설정할 때 사용되는 속성

```css
div {
  width: 50%;
  height: 50%;
}

/* 부모 요소 너비의 50%, 부모 요소 높이의 50% */
```

```css

  /* 스크린의 너비가 500px 이하일 경우 적용시킬 스타일 시트를 적습니다. */
}
```

## [rem]

<!-- CSS-JS/class-css/section04/04-01/03-rem.html 참고 -->

> 상대적인 단위, **root em**의 약자  
> 최상위 html 요소의 font-size 속성 값에 비례하여 값을 결정

```txt
/* font-size : 16px 인 경우 */

1rem => 16 * 1 = 16px
0.8rem => 16 * 0.8 = 12.8px
3rem => 16 * 3 = 48px
```

```css
padding: 2rem; /* (2* 16px ) = 32px */
```

# #반응형과 grid 조합

<!-- CSS-JS/class-css/section04/04-02/01-grid.html 참고 -->

> **grid** : 수평과 수직 모두 고려한 2차원 바둑판식 정렬 방법

## 1. grid-template

- `grid`의 행&열의 개수 및 크기를 지정

```css
grid-template-rows: 1fr 2fr 200px; /* 행 */
grid-template-columns: 1fr 2fr 200px; /* 열 */

grid-template-columns: repeat(4, 1fr); /* 1fr규격의 템플릿을 4개 생성 */
grid-template-columns: 1fr 1fr 1fr 1fr;
```

- 단위 : `fr`
  - `fracion(분수)`의 약자
- `repeat()` : 반복함수

## 2. column-gap 및 row-gap

- 열과 행 사이의 간격

```css
column-gap: 50px; /* 열 사이 */
row-gap: 50px; /* 행 사이 */
```

## 3. place-items

- 그리드 항목을 컨테이너 내에서 정렬

```css
place-items: center start; /* 상자아이템 각각 정렬 -> 상하 방향은 가운데, 좌우 방향은 왼쪽 */
```

## 4. place-content

- 그리드 컨테이너 전체의 위치를 조정

```css
place-items: center start; /* 상자아이템 각각 정렬 -> 그리드 컨테이너 내의 전체 내용이 상하 방향은 아래쪽, 좌우 방향은 가운데에 정렬 */
```

# #flex vs grid

<!-- CSS-JS/class-css/section04/04-02/02-grid-vs-flex.html 참고 -->

## [flex]

- 비교적 작은 단위의 레이아웃 구성에 적합
- 작업 유동성이 높기 때문에, 디자인이나 기획이 확실하게 잡히지 않아 변경 가능성이 있는 경우에 적합

## [grid]

- 큰 규모의 레이아웃 구성에 적합
- 레이아웃 구조가 확실하게 잡혀있는 경우, 효율적으로 반응형 디자인을 구현할 수 있음
- 단, 그리드는 상대적으로 최신 기술이기 때문에 모든 브라우저에서 지원하지 않음

## [flex와 grid의 혼합]

```css
.CSS_상자그룹 {
  display: flex;
  flex-wrap: wrap; /* 화면사이즈 작아지면, 사진 한개씩 아래로 내려줘 */
  gap: 10px;
  max-width: 1100px;
  height: 100%;
  background-color: skyblue;
  padding: 50px;
}
.CSS_상자 {
  width: 250px;
  height: 250px;
}

/* 사진 2개 이하일 때, 그리드로 변경(아래로 안 내려가고, 가로 사이즈만 줄음 => width 100%란? 가능한 범위에서 꽉차게를 의미) */
@media (max-width: 650px) {
  .CSS_상자그룹 {
    display: grid;
    grid-template-columns: 1fr 1fr;
  }
  .CSS_상자 {
    width: 100%;
  }
}
```
