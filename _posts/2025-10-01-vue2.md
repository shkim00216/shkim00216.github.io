# #뷰 애플리케이션의 기본 구조

## [package.json]

> 기본 정보, 의존성 모듈 정보, 스크립트 명령어 정보 등을 담고 있음

```json
{
  "name": "npm-vue",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "engines": {
    "node": "^20.19.0 || >=22.12.0"
  },
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "vue": "^3.5.22"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^6.0.1",
    "vite": "^7.1.7",
    "vite-plugin-vue-devtools": "^8.0.2"
  }
}
```

- `name` : 뷰 애플리케이션의 이름을 나타내는 문자열
- `version` : 뷰 애플리케이션의 버전을 나타내는 문자열
  - "0.0.0"은 [major],[minor],[patch] 버전을 의미
  - **major** : 하위 호환성이 없는 변경 사항이 있을 때 증가
  - **minor** : 하위 호환성이 있는 기능을 추가하거나 변경 사항이 있을 때 증가
  - **patch** : 버그나 작은 수정사항 있을 때 증가
- `private` : 뷰 애플리케이션의 공개 여부를 의미하는 논리형 값
  - true -> 비공개(공개 저장소에 배포하지 않는다는 뜻)
- `scripts` : 뷰 애플리케이션을 빌드하거나 실행할 수 있는 명령어를 등록하는 부분, 객체 형태로 작성, `npm run` 명령어로 실행할 수 있음
- `dependencies` : 뷰 애플리케이션을 실행할 때 필요한 의존성 모듈을 정의하는 부분
- `devDependencies` : 뷰 애플리케이션을 개발할 때 필요한 의존성 모듈을 정의하는 부분

```bash
npm install [패키지명] [--save | --save-dev]
```

- `--save` 옵션 -> dependencies에 설치
- `--save-dev` 옵션 -> devDependencies에 설치

## [index.html]

> 개발 서버가 구동되면 가장 먼저 서버에 로드

```html
<!DOCTYPE html>
<html lang="">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" href="/favicon.ico" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite App</title>
  </head>
  <body>
    <!-- 1 -->
    <div id="app"></div>
    <!-- 2 -->
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

1. id 속성의 값이 "app"인 HTML 요소를 루트 요소로 지정
2. main.js 모듈을 불러오는 부분

## [main.js]

> 뷰 애플리케이션을 초기화하고 구성하는 역할

```javascript
import "./assets/main.css"; // 1

import { createApp } from "vue"; // 2
import App from "./App.vue"; // 3

createApp(App).mount("#app"); // 4
```

1. 컴포넌트에 스타일 적용
2. vue 패키지에서 함수 가져옴
3. App.vue 파일 불러옴 -> 루트 컴포넌트
4. 뷰 애플리케이션의 인스턴스 생성

## [App.vue]

> **루트 컴포넌트** : 뷰 애플리케이션이 최초로 진입하는 가장 상위에 있는 컴포넌트

# #뷰 애플리케이션 인스턴스

## [인스턴스]

> 클래스의 실체화된 객체를 의미, 특정 클래스의 상태를 나타냄

- **클래스**가 객체를 생성하기 위한 템플릿이라면, **인스턴스**는 해당 클래스의 실제 객체

```javascript
import "./assets/main.css";

import { createApp } from "vue"; // 1
import App from "./App.vue";

createApp(App).mount("#app"); // 2
```

1. `createApp()` 함수는 뷰 패키지에 정의된 Vue 클래스의 인스턴스를 생성하는 역할을 하는 함수
2. `createApp()` 함수로 Vue 인스턴스 생성하고, 생성한 인스턴스를 `mount()` 함수로 HTML DOM과 연결

## [인스턴스의 구성 요소]

```javascript
// main.js
import { createApp, h } from "vue";

createApp({
  data() {
    return {
      message: "Hello, Vue!",
    };
  },
  methods: {
    reverse() {
      this.message = this.message.split("").reverse().join("");
    },
  },
  render() {
    // data와 methods에 정의한 속성 사용
    return h("div", [
      h("p", this.message),
      h("button", { onClick: this.reverse }, "Reverse"),
    ]);
  },
}).mount("#app");
```

- **인스턴스의 구성 요소** : `data`, `methods`, `render`와 같은 속성들

## [SFC의 구조]

> **단일 구성 요소** : 하나의 파일에 인스턴스 구성 요소와 관련한 모든 코드가 포함되는 형식

```html
<!-- App.vue -->
<script>
  export default {};
</script>
<template></template>
<style></style>
```

### 1. \<script> 태그 영역

- SFC 파일에서 사용할 로직을 자바스크립트로 작성
- **옵션스 API** : 뷰에서 객체를 작성할 때 지켜야 하는 문법 규칙

### 2. \<template> 태그 영역

- HTML 코드 작성
- `<script>` 태그 영역에서 작성한 여러 속성으로 정의한 값들과 연동할 수 있음

### 3. \<style> 태그 영역

- CSS 스타일을 적용하기 위해 사용

# #기본 문법 다루기

## [옵션스 API 사용하기]

> 뷰에서 약속된 속성을 사용해야 함

| 속성               | 설명                                                    |
| ------------------ | ------------------------------------------------------- |
| `data`             | 데이터(data)를 저장하는 속성                            |
| `methods`          | 함수(function)를 저장하는 속성                          |
| `computed`         | 데이터에 기반해 계산된 속성                             |
| `watch`            | 데이터의 변화를 감시하기 위한 속성                      |
| `props`            | 사용자 정의 데이터를 수신하기 위한 속성                 |
| `emits`            | 발신 가능한 부모 컴포넌트의 이벤트를 정의하기 위한 속성 |
| `provide`          | 하위 컴포넌트에 데이터를 주입하기 위한 속성             |
| `inject`           | 상위 컴포넌트에 주입된 데이터를 받기 위한 속성          |
| `Life Cycle Hooks` | 컴포넌트의 특정 시점에 따라 자동으로 호출되는 콜백 함수 |

## [데이터 정의하기]

<!-- App.vue -->

        age: 19,
      };
    },
  };

## [데이터 보간 사용하기]

<!-- App.vue -->

## [디렉티브 사용하기]

> 뷰에서만 사용하는 문법, 접두사 v-가 붙음

### 1. v-html

- 값에 HTML 태그가 포함되었으면 값을 단순 텍스트로 치환해 출력
- ❗️ XSS 공격에 매우 취약하므로 사용자가 입력한 데이터를 출력할 때는 사용 불가, 개발자가 직접 작성한 데이터를 출력할 때만 사용해야 함 ❗️

```html
<!-- App.vue/v-html -->
<script>
  export default {
    data() {
      return {
        message: "<h1>Hello, Vue JS!</h1>",
      };
    },
  };
</script>

<template>
  <div v-html="message"></div>
</template>

<!-- 결과 -->
<!-- Hello, Vue JS! -->
```

### 2. v-text

- 값을 단순하게 텍스트로 출력하게 하는 디렉티브

```html
<!-- App.vue/v-text -->
<template>
  <div v-text="message"></div>
</template>

<!-- 결과 -->
<!-- <h1>Hello, Vue JS!</h1> -->
```

### 3. v-pre

- 컴파일할 때 `<template>` 태그 영역을 건너뛰게 하는 디렉티브
- 컴파일에서 제외되어 단순하게 텍스트로 취급되어 그대로 출력

```html
<!-- App.vue/v-pre -->
<script>
  export default {
    data() {
      return {
        message: "Hello, Vue JS!",
      };
    },
  };
</script>

<template>
  <div v-pre>{{ message }}</div>
</template>

<!-- 결과 -->
<!-- {{ message }} -->
```

### 4. v-bind

- HTML 태그의 속성 앞에 콜론을 붙여 표시하며 속성과 데이터를 연결할 수 있음
- 현업에서는 축약형을 많이 사용함

```html
<!-- App.vue/v-bind -->
<script>
  export default {
    data() {
      return {
        className: "red-color",
      };
    },
  };
</script>

<template>
  <h1 v-bind:class="className">Hello, Vue JS</h1>
  <!-- 축약형 -->
  <h1 :class="className">Hello, Vue JS</h1>
</template>

<style>
  .red-color {
    color: red;
  }
</style>
```

### 5. v-if/v-else-if/v-else

- `<template>` 태그 영역에서 조건부 렌더링 기능을 구현하는 디렉티브
- **조건부 렌더링** : 디렉티브에 할당된 값의 참/거짓에 따라 HTML 요소를 렌더링하거나 렌더링하지 않는 것을 의미
- 거짓일 때 `v-if` 부분이 주석 처리되어 요소가 DOM에 추가되지 않음

```html
<!-- App.vue/v-if -->
<script>
  export default {
    data() {
      return {
        condition: "A",
      };
    },
  };
</script>

<template>
  <p v-if="condition === 'A'">condition 데이터의 값은 A입니다.</p>
  <p v-else-if="condition === 'B'">condition 데이터의 값은 B입니다.</p>
  <p v-else-if="condition === 'C'">condition 데이터의 값은 C입니다.</p>
  <p v-else-if="condition === 'D'">condition 데이터의 값은 D입니다.</p>
  <p v-else>어떤 조건에도 해당하지 않습니다.</p>
</template>

<!-- 결과 -->
<!-- condition 데이터의 값은 A입니다. -->
```

### 6. v-show

- 디렉티브의 값의 참/거짓에 따라 `<template>` 태그 영역에 작성된 요소를 숨기거나 보여줌
- 거짓일 때 CSS의 `display` 속성으로 감춤

```html
<!-- App.vue/v-show -->
<script>
  export default {
    data() {
      return {
        condition: true,
      };
    },
  };
</script>

<template>
  <p v-show="condition">v-show 디렉티브는 조건이 참입니다.</p>
  <p v-show="!condition">v-show 디렉티브는 조건이 거짓입니다.</p>
</template>

<!-- 결과 -->
<!-- v-show 디렉티브는 조건이 참입니다. -->
```

#### 💡 v-if/v-show

- 조건이 자주 변경되는 경우 -> `v-show`
- 조건이 자주 변경되지 않는 경우 -> `v-if`

### 7. v-cloak

- 뷰 애플리케이션의 렌더링 과정에서 데이터 바인딩이 완료되기 전에 데이터가 화면에 노출되는 것을 막기 위해 사용

```html
<!-- cdn test -->
<!-- index.html/v-cloak -->
<head>
  <style>
    [v-cloak] {
      display: none;
    }
  </style>
</head>
<body>
  <div id="app">
    <h1 v-cloak>{{ message }}</h1>
  </div>
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <script>
    const { createApp } = Vue;
    window.setTimeout(() => {
      createApp({
        data() {
          return {
            message: "Hello Vue!",
          };
        },
      }).mount("#app");
    }, 2000);
  </script>
</body>
```

### 8. v-for

- 뷰에서 반복적으로 렌더링하는 HTML 요소를 생성하는 데 사용

```javascript
v-for="값 in 배열" key="고유값"
v-for="(값, 인덱스) in 배열" key="고유값"
```

```html
<!-- App.vue/v-for -->
<script>
  export default {
    data() {
      return {
        fruits: ["apple", "banana", "orange"],
      };
    },
  };
</script>

<template>
  <h1>fruits 데이터의 반복 결과</h1>
  <ul>
    <li v-for="(fruit, index) in fruits" :key="index">
      인덱스: {{ index }}, 값: {{ fruit }}
    </li>
  </ul>
</template>

<!-- 결과 -->
<!-- 인덱스: 0, 값: apple
인덱스: 1, 값: banana
인덱스: 2, 값: orange -->
```

- 객체가 할당된 데이터 속성의 값도 `v-for` 디렉티브로 반복 가능

```javascript
v-for="값 in 객체" key="고유값"
v-for="(값, 키) in 객체" key="고유값"
v-for="(값, 키, 인덱스) in 객체" key="고유값"
```

```html
<!-- App.vue/v-for -->
<script>
  export default {
    data() {
      return {
        user: {
          name: "John",
          age: 20,
          gender: "male",
        },
      };
    },
  };
</script>

<template>
  <h1>user 데이터의 반복 결과</h1>
  <ul>
    <li v-for="(value, key, index) in user" :key="index">
      {{ index }}: {{ key }} : {{ value }}
    </li>
  </ul>
</template>

<!-- 결과 -->
<!-- 0: name : John
1: age : 20
2: gender : male -->
```

# #이벤트 다루기

> **이벤트(event)** : 사용자와 상호작용해서 발생하는 일련의 사건

## [v-on 디렉티브와 methods 옵션 속성으로 이벤트 연결하기]

- `v-on` 디렉티브로 이벤트 연결
  - `v-on:이벤트_타입="이벤트_핸들러"`

1. 이벤트 타입

   - 예) `click`, `keyup`, `keydown` 등
   - 이벤트 종류를 식별하는 문자열로 자바스크립트와 개념이 같음

2. 이벤트 핸들러

   - 이벤트 타입과 일치하는 이벤트가 발생하면 실행되는 함수
   - ```javascript
     export default {
       methods: {}, // 메서드 정의
     };
     ```

📌 [자바스크립트의 이벤트 타입](https://developer.mozilla.org/en-US/docs/Web/API/Element)

```html
<!-- App.vue/v-on -->
<script>
  export default {
    methods: {
      // ES6의 단축 메서드명으로 표기
      clickHandler() {
        alert("click!");
      },
    },
  };
</script>

<template>
  <button type="button" v-on:click="clickHandler">클릭</button>
  <button type="button" v-on:dblclick="clickHandler">더블클릭</button>
  <!-- 축약형 -->
  <button type="button" @dblclick="clickHandler">더블클릭</button>
</template>
```

## [이벤트 객체 사용하기]

> **이벤트 객체** : 특정 이벤트에 대한 상세 정보를 가지고 있는 객체

```html
<!-- App.vue/event -->
<script>
  export default {
    methods: {
      clickHandler(event, message) {
        console.log(event);
      },
    },
  };
</script>

<template>
  <button type="button" @click="clickHandler($event)">클릭</button>
  <!-- 화살표 함수 사용 -->
  <button type="button" @click="($event) => clickHandler($event)">클릭</button>
  <!-- 이벤트 객체와 값을 함께 사용 -->
  <button type="button" @click="clickHandler($event, 'Hello')">클릭</button>
</template>
```

## [수식어 사용하기]

> **수식어(modifier)** : 이벤트 처리 방식을 제어하는 데 사용하는 기능

- 일반적인 DOM 이벤트 동작을 변경하거나 기능을 추가할 수 있음
- `@이벤트_타입.수식어`

```html
<!-- App.vue/modifier -->
<script>
  export default {
    methods: {
      // onkeyupHandler(e) {
      //   // 키보드 이벤트 객체에서 keyCode 속성 13은 Enter 키
      //   if (e.keyCode === 13) {
      //     console.log("Enter!");
      //   }
      // },
      onkeyupHandler() {
        console.log("Enter!");
      },
    },
  };
</script>

<template>
  <!-- <input type="text" @keyup="($event) => onkeyupHandler($event)" /> -->
  <!-- 수식어 사용 -->
  <input type="text" @keyup.enter="onkeyupHandler" />
</template>
```

## [이벤트와 반응성]

> **반응성(reactivity)** : 데이터의 변화를 감지하고 자동으로 화면 UI를 업데이트하는 기능

- 뷰 애플리케이션은 값이 바뀌면 이를 감지하고 화면을 다시 렌더링
- 뷰의 반응성으로 새로고침 발생하지 않고, 해당 값으로 인해 변경된 부분만 업데이트

### 1. v-once 디렉티브로 화면 업데이트 막기

- `v-once` 디렉티브는 정적 디렉티브로, 어떠한 요소든지 한 번만 렌더링하고 그 이후에는 렌더링하지 않음

```html
<!-- App.vue/v-once -->
<script>
  export default {
    data() {
      return {
        number: 0,
      };
    },
    methods: {
      increasement() {
        this.number++;
      },
    },
  };
</script>

<template>
  <!-- 한 번 렌더링 후 렌더링되지 않음 -->
  <h1 v-once>{{ number }}</h1>
  <button type="button" @click="increasement">증가</button>
</template>
```

### 2. v-memo 디렉티브로 렌더링 결과 저장하기

> **메모이제이션(memoization)** : 이전에 계산한 결과를 저장해 중복 계산을 피하고 실행 속도를 향상시키는 프로그래밍 기술

- `v-memo` 디렉티브를 사용해 렌더링 결과를 저장하면 렌더링이 반복되는 것을 방지해 실행 속도를 향상할 수 있음
- `<태그 v-memo="[조건1, 조건2, ...]"></태그>`

```html
<!-- App.vue/v-memo -->
<script>
  export default {
    data() {
      return {
        name: "철수",
        gender: "남자",
        age: 20,
      };
    },
  };
</script>

<template>
  <!-- 이름과 성별 변경만 다시 렌더링됨 -->
  <div v-memo="[name, gender]">
    <p>이름: {{ name }}</p>
    <p>성별: {{ gender }}</p>
    <p>나이: {{ age }}</p>
  </div>
  <button @click="name = '영희'">이름 변경</button>
  <button @click="gender = '여자'">성별 변경</button>
  <!-- 실제 데이터는 변경되지만 화면은 렌더링되지 않음 -->
  <button @click="age = 30">나이 변경</button>
</template>
```

❗️ `v-memo` 디렉티브는 1,000번 이상 반복되는 요소에 사용하면 효과볼 수 있음

## [폼 이해하기]

- 폼 관련 요소는 사용자에게 값을 입력받아 서버로 전송하기 위해 사용

### 1. \<form> 태그에서 입력받은 값을 action 속성에 지정된 경로로 전송해 처리하는 방법

- 단점 : 사용자가 값을 입력한 페이지에서 다른 페이지로 이탈해 버림

```html
<!-- form_ex_1.html -->
<form action="/login_process.php">
  <label for="uid">아이디: <input type="text" id="uid" /></label>
  <label for="upw">비밀번호: <input type="text" id="upw" /></label>
  <button type="submit">로그인</button>
</form>
```

### 2. 입력 값을 자바스크립트로 가져와서 AJAX를 사용해 전송하는 방법

- 사용자 입력 데이터를 전송하면서 페이지를 이동하지 않아도 되어 데이터를 전송한 후 처리 방법의 자유도가 높음

```html
<!-- form_ex_2.html -->
<div id="app">
  <form id="loginForm">
    <label for="uid">아이디: <input type="text" id="uid" /></label>
    <label for="upw">비밀번호: <input type="text" id="upw" /></label>
    <button type="submit">로그인</button>
  </form>
  <script>
    document
      .getElementById("loginForm")
      .addEventListener("submit", function (event) {
        event.preventDefault(); // 폼 전송 이벤트 취소
        // 요소에 입력된 값 가져오기
        const uid = document.getElementById("uid").value;
        const upw = document.getElementById("upw").value;
        // AJAX 요청 만들기
        const xhr = new XMLHttpRequest();
        xhr.open("POST", "/login_process.php", true);
        // AJAX 응답 설정하기
        xhr.onreadystatechange = function () {
          if (xhr.readyState === XMLHttpRequest.DONE) {
            if (xhr.status === 200) {
              // 요청이 성공할 경우
              const response = xhr.responseText;
              console.log(response);
            } else {
              // 요청이 실패할 경우
              console.error("Request failed with status " + xhr.status);
            }
          }
        };
        // 데이터 전송 준비하기
        const formData = new FormData();
        formData.append("uid", uid);
        formData.append("upw", upw);
        // AJAX로 데이터 전송 요청하기
        xhr.send(formData);
      });
  </script>
</div>
```

## [폼 요소와 이벤트]

### 1. input 이벤트

- 입력 요소의 값이 변경될 때 발생하는 이벤트
- IME 사용 시 값이 한 글자씩 늦게 인식되는 문제 해결

```html
<!-- App.vue/event-input -->
<script>
  export default {
    data() {
      return {
        message: "",
      };
    },
    methods: {
      onChangeHandler($event) {
        this.message = $event.target.value;
      },
    },
  };
</script>

<template>
  <!-- v-model 디렉티브 대신 input 이벤트로 함수 호출 -->
  <input type="text" v-model="message" @input="onChangeHandler($event)" />
  {{ message }}
</template>
```

### 2. change 이벤트

- 폼 요소의 값이 변경되면 발생하는 이벤트
- 사용자가 선택한 값에 따른 추가 작업이 필요할 때 `change` 이벤트 사용

```html
<!-- App.vue/event-change -->
<script>
  export default {
    data() {
      return {
        selected: "banana",
        price: 500,
      };
    },
    methods: {
      onChangeHandler($event) {
        if (this.selected === "banana") {
          this.price = 500;
        }
        if (this.selected === "apple") {
          this.price = 700;
        }
      },
    },
  };
</script>

<template>
  <select v-model="selected" @change="onChangeHandler">
    <option value="banana">바나나</option>
    <option value="apple">사과</option>
  </select>
  가격: {{ price }}원
</template>
```

### 3. submit 이벤트

- `<form>` 태그에 사용한 폼 요소의 데이터를 서버로 전송하는 시점에서 발생하는 이벤트

```html
<!-- App.vue/event-submit -->
<script>
  export default {
    methods: {
      onSubmitHandler(e) {
        e.preventDefault();
        // 별도의 폼 전송 처리
        console.log("onSubmit Handler!");
      },
    },
  };
</script>

<template>
  <form @submit="onSubmitHandler">
    <button type="submit">전송</button>
  </form>
</template>
```

- 입력 요소에서 키보드의 키를 눌렀다가 뗐을 때 발생하는 이벤트
- 주로 사용자의 키 입력에 따라 코드를 동적으로 처리해야 하는 경우에 유용

# #계산된 속성과 감시자 속성

## [계산된 속성]

> **계산된 속성(computed)** : 옵션스 API에서 제공하는 속성 중 하나로, computed 옵션 속성으로 정의해 사용

- `computed` 옵션 속성 : 컴포넌트에서 자주 사용하는 데이터를 캐시해 애플리케이션의 성능을 향상시킴

```html
<!-- App.vue/computed -->
<script>
  export default {
    data() {
      return {
        firstName: "Gildong",
        lastName: "Hong",
      };
    },
    computed: {
      fullName() {
        console.log("computed fullname");
        return `${this.lastName} ${this.firstName}`;
      },
    },
  };
</script>

<template>
  <!-- 콘솔에는 한 번만 찍힘 => 데이터 값이 변경되기 전까지 캐싱된 값을 보여줌 -->
  <h1>{{ fullName }}</h1>
  <h1>{{ fullName }}</h1>
</template>
```

- 예) 숫자 배열에서 짝수만 찾아 총합을 출력하는 코드

```html
<!-- App.vue/computed-ex -->
<script>
  export default {
    data() {
      return {
        numArr: [1, 2, 3, 4, 5],
      };
    },
    computed: {
      evenSum() {
        return this.numArr
          .filter((v) => v % 2 === 0) // true값을 반환하는 모든 값으로 구성된 새 배열 생성
          .reduce((acc, cur) => acc + cur, 0); // 이전값 + 현재값, 인덱스 0부터 계산된 값 저장
      },
    },
  };
</script>

<template>
  <h1>{{ evenSum }}</h1>
</template>

<!-- 결과 -->
<!-- 6 -->
```

## [감시자 속성]

> **감시자 속성(watch)** : 옵션스 API에서 제공하는 속성 중 하나로 watch 옵션 속성으로 정의해 사용

- `watch` 옵션 속성은 감시자 속성이라는 명칭에 걸맞게 데이터의 변경을 감시하고, 변경이 감지될 때마다 특정 동작을 수행

### 기본 사용법

- `watch` 옵션 속성은 데이터 속성과 같은 식별자를 사용하는 함수를 값으로 가짐

```html
<!-- App.vue/watch-shallow -->
<script>
  export default {
    data() {
      return {
        inputStr: "",
      };
    },
    watch: {
      inputStr(newValue, oldValue) {
        console.log(`old value : ${oldValue}`);
        console.log(`new value : ${newValue}`);
        // 콘솔 확인 시 이전 값과 새로운 값 출력
      },
    },
  };
</script>

<template>
  <input type="text" v-model="inputStr" />
</template>
```

### 깊은 사용법

- `watch` 옵션 속성은 기본적으로 null에서 0이 할당되는 순간을 감지하지 못함
- 배열에 새로운 값을 추가하거나 객체의 속성을 변경해도 확인되지 않음

```html
<!-- App.vue/watch-non-deep -->
<script>
  export default {
    data() {
      return {
        arr: [0, 1, 2],
        obj: { name: "chulsu" },
      };
    },
    watch: {
      // 배열이나 객체의 변경을 감지하지 못함
      arr(newValue, oldValue) {
        console.log(`old value: ${oldValue}`);
        console.log(`new value: ${newValue}`);
      },
      obj(newValue, oldValue) {
        console.log(`old value: ${JSON.stringify(oldValue)}`);
        console.log(`new value: ${JSON.stringify(newValue)}`);
      },
    },
  };
</script>

<template>
  <h1>{{ arr }}</h1>
  <h1>{{ obj }}</h1>
  <button @click="arr.push(3)">배열 변경</button>
  <button @click="obj.age = 20">객체 변경</button>
</template>
```

#### ⭐️ 깊은 사용법의 형식

```javascript
watch: {
  // 감시할 데이터나 계산된 속성
  dataOrComputed: {
    // 변경이 감지될 때 실행할 콜백 함수
    handler(newVal, oldVal) {
      // 변경이 감지될 때 수행할 동작
    },
    // 감시할 데이터나 계산된 속성이 변경될 때마다 콜백 함수를 호출할지 여부(기본값: false)
    deep: false,
    // 초기 렌더링 시 콜백 함수를 호출할지 여부(기본값: false)
    immediate: false,
  },
}
```

- `watch` 옵션 속성

| 속성                      | 설명                                                                                                                                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dataOrComputed`          | 데이터(data)나 계산된 속성(computed)의 키(key)를 적음                                                                                                                                                                                    |
| `handler(newVal, oldVal)` | 변경 사항이 있을 때 실행할 함수를 정의, 새로운 값과 이전 값을 매개변수로 받음                                                                                                                                                            |
| `deep`                    | 중첩된 객체 또는 배열의 내부 변경을 감시할지 설정, true면 감시하고 false면 감시하지 않음                                                                                                                                                 |
| `immediate`               | 초기 렌더링 시 콜백 함수를 호출할지 설정, true면 호출하고 false면 호출하지 않음                                                                                                                                                          |
| `flush`                   | 콜백 함수의 실행 타이밍을 결정, 데이터 변경이 뷰에 반영되고 콜백 함수가 호출되길 원하면 'post', 뷰에 반영되기 전에 콜백 함수부터 호출되길 원하면 'pre', 하나의 동작에 여러 번 변경되더라도 동기적으로 모든 변화를 감시하고 싶다면 'sync' |
| `once`                    | true로 지정하면 변경 사항을 한 번만 감시                                                                                                                                                                                                 |

```html
<!-- App.vue/watch-deep -->
<script>
  export default {
    data() {
      return {
        arr: [0, 1, 2],
        obj: { name: "chulsu" },
      };
    },
    watch: {
      // 깊은 사용법 실행 - 객체나 배열의 변화 감시 가능
      arr: {
        handler(newValue, oldValue) {
          console.log(`old value: ${oldValue}`);
          console.log(`new value: ${newValue}`);
        },
        deep: true,
      },
      obj: {
        handler(newValue, oldValue) {
          console.log(`old value: ${oldValue}`);
          console.log(`new value: ${newValue}`);
        },
        deep: true,
      },
    },
  };
</script>

<template>
  <h1>{{ &#123;&#123; arr &#125;&#125; }}</h1>
  <h1>{{ obj }}</h1>
  <button @click="arr.push(3)">배열 변경</button>
  <button @click="obj.age = 20">객체 변경</button>
</template>
```

# #스타일 다루기

## [인라인 스타일]

- HTML처럼 태그에 `style` 속성을 사용해 스타일을 지정

### 1. style 속성만 사용하기

```html
<!-- App.vue/inline-style-basic -->
<template>
  <h1 style="color: red; font-style: italic">Inline Style</h1>
</template>
```

### 2. v-bind 디렉티브와 함께 사용하기

- 요소의 스타일을 동적으로 바인딩하고 싶다면 `style` 속성과 함께 `v-bind` 디렉티브를 사용

```html
<!-- App.vue/inline-style-v-bind -->
<script>
  export default {
    data() {
      return {
        primaryColor: "red",
        primaryStyle: "italic",
      };
    },
  };
</script>

<template>
  <!-- 카멜 케이스로 작성 -->
  <h1 :style="{ color: primaryColor, fontStyle: primaryStyle }">
    Inline Style
  </h1>
</template>
```

## [내부 스타일]

- `<style>` 태그 영역 사용
- 스타일이 모든 컴포넌트에 공통으로 적용되므로 `scoped` 속성을 함께 사용해야 해당 컴포넌트에만 스타일 적용

```html
<!-- App.vue/internal-style -->
<template>
  <h1>Internal Style</h1>
</template>

<style scoped>
  h1 {
    color: red;
    font-style: italic;
  }
</style>
```

## [외부 스타일]

- CSS 파일을 따로 작성해 스타일을 지정하는 방법
- 관례상 src 폴더 하위에 있는 `assets` 폴더에 작성

```css
/* src/assets/main.css */
h1 {
  color: red;
  font-style: italic;
}
```

```html
<!-- App.vue/external-style -->
<template>
  <h1>External Style</h1>
</template>

<style>
  /* 외부 CSS 파일의 경로는 다양하게 작성 가능 */
  /* @import "./assets/main.css";
@import "../src/assets/main.css"; */
  @import "@/assets/main.css"; /* vite.config.js 파일에 작성된 vite 설정값 때문 */
  @import "~/main.css"; /* vite.config.js 파일에 작성된 vite 설정값 추가 */
</style>
```

```javascript
// vite.config.js
import { fileURLToPath, URL } from "node:url";

import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";
import vueDevTools from "vite-plugin-vue-devtools";

// https://vite.dev/config/
export default defineConfig({
  plugins: [vue(), vueDevTools()],
  resolve: {
    alias: {
      "@": fileURLToPath(new URL("./src", import.meta.url)),
      "~": fileURLToPath(new URL("./src/assets", import.meta.url)),
    },
  },
});
```
