## 쌓임맥락과 Z-index

### Z-index

<!-- CSS-JS/class-css/section05/05-01/01-z-index.html 참고 -->

<abbr title="zIndex">**Z-index** : 요소의 쌓임 순서를 결정하는 속성, 화면의 정면 축으로 올라오는 인덱스</abbr>

- 양수 `z-index` : 요소가 기본 쌓임 순서보다 위에 쌓임
- 0 또는 음수 `z-index` : 요소가 기본 쌓임 순서나, 그 아래에 쌓임
- `z-index`가 설정되지 않은 경우 : 기본 쌓임 순서대로 배치됨

### 쌓임맥락

<!-- CSS-JS/class-css/section05/05-01/02-stacking-context1.html 참고 -->

<abbr title="stackingContext">**쌓임맥락(Stacking Context)** : 태그들 쌓아 올리는 도화지</abbr>

1. `position` 속성이 `relative`, `absolute`, `fixed`인 경우 : `z-index`가 설정된 경우에만 새로운 쌓임 맥락 생성
2. `opacity`가 1보다 작은 경우 : `opacity` 속성이 1보다 작으면 해당 요소는 새로운 쌓임 맥락을 생성
3. `transform`, `filter`, `perspective` 속성이 설정된 경우 : 이 속성들이 적용된 요소도 새로운 쌓임 맥락을 만듬

<!-- CSS-JS/class-css/section05/05-01/02-stacking-context2.html 참고 -->
<fieldset>
  <b>⚠️ 쌓임맥락 부모/자식</b><br>
  같은 position으로 묶였을 때 쌓임맥락 부모/자식으로 볼 수 있음
</fieldset>

### 리팩토링

<!-- CSS-JS/class-css/section05/05-01/03-overlay-refactoring.html 참고 -->

<abbr title="refactoring">**리팩토링** : 기능은 똑같지만, 더 좋은 코드로 다시 만들기</abbr>

<fieldset>
  <b>⚠️ 겹치기 방식의 문제점</b><br>
  - position: absolute는 문서 흐름에서 제거됨
  - 다른 요소는 이 요소의 존재를 인식하지 못하여 다른 요소와 겹칠 수 있음
  - 사진을 겹쳐서 표시하고 싶을 때, relative, absolute 속성 활용
</fieldset>

## 모달과 중첩모달

### 모달

<!-- CSS-JS/class-css/section05/05-02/01-modal-background.html 참고 -->

<abbr title="modal">**모달** : 내가 만드는 예쁜 경고창(또는 입력창)</abbr>

#### ⭐️ 예시

- **로그인 창** : 로그인 창이 나타나면, 사용자는 로그인을 완료하거나 창을 닫기 전까지 다른 곳을 클릭할 수 없음
- **확인 메시지** : 중요한 작업을 하기 전에 "정말 이 작업을 진행하시겠습니까?"라는 메시지가 모달로 나타날 수 있음

```css
.CSS_모달배경 {
  display: none;
}
```

```javascript
const JS_모달열기기능 = () => {
  document.getElementById("HTML_모달배경").style = "display: block;";
};
```

#### 💡 %? vw? vh?

```css
width: 100vw;
height: 100vh;
```

- `vw` / `vh` : `Viewport Width` / `Viewport Height`의 약자, 브라우저의 너비를 기준으로 한 상대 단위
- `%` : 부모 요소에 대한 상대적인 크기나 위치, 정도를 지정할 때 사용

#### 💡 calc()

<!-- CSS-JS/class-css/section05/05-02/02-modal-box.html 참고 -->

```css
top: calc(50% - 250px); /* 높이 500px의 절반인 250px을 중앙 정렬하기 위한 값 */
left: calc(50% - 200px); /* 너비 400px의 절반인 200px을 중앙 정렬하기 위한 값 */
```

`calc()` : 동적인 크기 계산을 가능하게 해주는 유용한 도구
