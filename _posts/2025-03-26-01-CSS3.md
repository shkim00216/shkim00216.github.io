# #포지션

> **position** : HTML 요소가 배치되는 방식을 결정하는 속성

## [position의 속성값]

- `position : static`(기본값)
  - 문서상 원래 있어야 하는 위치에 배치
  - ❗️ `top, left, bottom, right` 속성 사용 불가
  - 위치 조정이 불가능한 기본 HTML 요소의 상태
- `position : relative`
  - 원래 있던 자리를 기준으로 요소의 위치를 조정
- `position : absolute`
  - 절대 좌표를 기준으로 요소의 위치를 조정
- `position : fixed`
  - viewport를 기준으로 요소의 위치를 조정
  - 화면 어딘가에 위치 고정
- `position : sticky`
  - 부모 요소의 좌표 기준으로 요소의 위치를 조정
  - 해당 요소의 위치 아래로 스크롤이 내려가면 지정한 좌표에 고정

# #스크롤

## 1. 세로스크롤

<!-- CSS-JS/class-css/section03/03-02/01-scroll1-y.html 참고 -->

- 웹 페이지나 특정 요소의 콘텐츠가 화면에 다 보여지지 않을 때, 사용자에게 위아래로 스크롤할 수 있는 기능을 제공하여 나머지 콘텐츠를 볼 수 있게 하는 기능

```css
overflow: scroll;
```

## 2. 가로스크롤

<!-- CSS-JS/class-css/section03/03-02/01-scroll2-x.html 참고 -->

- 웹 페이지나 특정 요소의 콘텐츠가 화면에 다 보여지지 않을 때, 사용자에게 좌우로 스크롤할 수 있는 기능을 제공하여 나머지 콘텐츠를 볼 수 있게 하는 기능

```css
overflow-x: scroll;
```

## 💡 가로스크롤을 만들기 위한 찌그러지지 않는 flex 기능

```css
flex-shrink: 0;
```

- 자식 요소는 지정된 크기 이상으로 줄어들지 않고, 지정된 크기를 유지하려고 함(스크롤 생김)

## [sticky vs fixed]

<!-- CSS-JS/class-css/section03/03-02/02-scroll-sticky.html 참고 -->

- 스티키(`position: sticky;`)
  - 스크롤을 따라 이동하다가 특정 임계점에서 고정
  - 요소의 부모 영역을 기준으로 동작
  - 부모 요소를 벗어나지 않음
- 고정(`position: fixed;`)
  - 항상 고정된 위치에 머뭄
  - 스크롤과 상관없이 브라우저 창을 기준으로 동작
  - 화면 내에서 위치가 변하지 않음

## [스크롤 헤더 배경 뿌옇게 만들기]
