# #개발 환경 설정하기

## [Node.js 설치]

> **Node.js** : 웹 브라우저 외부에서 자바스크립트를 실행할 수 있는 크로스 플랫폼 오픈소스 런타임 환경 제공

📌 [Node.js 설치 링크](https://nodejs.org/en/download)

1. 가장 높은 LTS 버전으로 설치 진행
2. 라이선스 동의 후 `Next` 클릭하여 설치 완료
3. 설치 확인 : cmd > `node -v` 명령어 입력 후 버전 확인

## [Vue CLI 설치]

> **CLI(Command Line Interface)** : 윈도우의 명령 프롬프트나 맥OS의 터미널에서 사용자가 명령어를 입력했을 때 컴퓨터가 그에 맞는 기능을 실행해주는 일련의 처리 방식

1. cmd > `vue --version` 명령어 입력 후 버전이 낮거나 없으면 설치 명령어 진행
2. `npm install -g @vue/cli`로 설치 진행

## [비주얼 스튜디오 코드 익스텐션 설치]

### 1. Vue - Official

- Vue에서 제공하는 문법과 파일을 인식할 수 있게 함

### 2. 그 외 익스텐션

- `Live Server` : 가상 서버를 이용해 작성한 HTML 코드를 실시간으로 확인할 수 있음
- `Prettier - Code formatter` : 코드를 일관된 형식으로 자동 정리해주는 도구
- `Auto Rename Tag` : 시작 태그와 종료 태그 같게 설정
- `HTML to CSS autocompletion` : HTML 문서에서 class 속성으로 작성한 값을 연결된 CSS 파일에서 자동 완성되도록 지원하는 익스텐션
- `HTML CSS Support` : CSS 파일에서 작성한 클래스나 아이디 선택자 값을 연결된 HTML 문서의 id나 class 속성의 값으로 적을 때 자동 완성 지원
- `Code Runner` : 자바스크립트 코드를 VSCode 내부에서 실행할 수 있게 지원하는 익스텐션
- `Material Icon Theme` : 비주얼 스튜디오 코드의 폴더 및 파일의 아이콘을 머터리얼 디자인으로 변경
- `Korean Language Pack for Visual Studio Code` : VSCode의 메뉴를 한국어로 변경해주는 익스텐션

## [웹 브라우저 설치]

### 확장 프로그램 설치

- `Vue.js devtools` : 뷰 애플리케이션을 디버깅하고 개발하는 데 도움을 주는 여러 기능을 사용할 수 있음

# #첫 번째 뷰 애플리케이션 만들기

## [CDN 사용하기]

```html
<body>
  <!-- vue 라이브러리 불러옴 -->
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <div id="app">{{ message }}</div>
  <script>
    const { createApp } = Vue;
    createApp({
      data() {
        // 값으로 객체를 반환하는 함수를 가지며, 함수에 반환되는 객체는 뷰 인스턴스에서 데이터로 사용됨
        return {
          message: "Hello Vue.js!",
        };
      },
    }).mount("#app"); // 뷰 인스턴스를 DOM과 연결 (id의 값이 app인 DOM과 연결)
  </script>
</body>
```

## [NPM 사용하기]

1. 해당 프로젝트 폴더로 VSCode 오픈 후 'Terminal > New Terminal' 새로운 터미널 열기
2. `npm create vue@latest` 명령어 입력
   - 명령어 실행이 안될 때 powershell을 관리자 권한으로 실행하여, `Set-ExecutionPolicy RemoteSigned` 코드 적용
3. `y` 입력 후 설치 진행
4. 프롬프트 값 입력
   - **Project name** : 뷰 애플리케이션의 이름 지정, 현재 폴더에 만들려면 마침표(.) 입력
   - **Package name** : 위 프로젝트 이름에 마침표 입력했을 때 나옴, 폴더 이름과 동일하게 입력
   - **Add TypoScript** : 뷰 애플리케이션에 타입스크립트 설정을 추가할지
   - **Add JSX Support** : 리액트에서 사용하는 JSX를 사용하고 싶을 때 Yes
   - **Add Vue Router for Single Page Application development** : Single Page Application을 만들기 위해 Vue Router 패키지를 추가할지
   - **Add Pinia for state management** : Pinia 추가할지
   - **Add Vitest for Unit Testing** : 유닛 테스트를 위한 Vitest 패키지를 추가할지
   - **Add an End-to-End Testing Solution** : 종간단 테스트를 위한 솔루션을 뷰 애플리케이션에 포함할지
   - **Add ESLint for code quality** : 코드 품질을 위해 ESLint 설정을 추가할지
   - **Add Vue DevTools 7 extension for debugging** : 뷰 애플리케이션을 디버깅하기 위한 Vue DevTools 익스텐션을 추가할지
5. `npm install` : package.json 파일을 참조해 패키지 설치하는 명령어
6. `npm run dev` : 뷰 애플리케이션을 실행하는 명령어
