# #데이터 타입

<!-- precamp/class/03-javascript/연습-05-variable-if.js 참고 -->

## [데이터 타입 종류]

> **원시타입(Primitive type)** : 불변성의 특징을 가짐

1. `문자열(String)` : 문자열은 “” 안에 적어주며, 따옴표 안에 적힌 값들은 숫자여도 문자열로 취급
2. `숫자(Number)` : 숫자를 나타내는 자료형이며 모든 숫자를 실수로 처리
   ❗️ **주의** 따옴표 없이 적어야 함 ❗️
3. `불린(Booolean)` : true(참), false(거짓)으로 나타내는 자료형
4. `undefined` : 변수를 선언했지만 값이 할당되지 않았을 때 자바스크립트 엔진이 암묵적으로 초기화 하는 값
5. `null` : 의도적으로 값이 없음을 명시하기 위해 할당하는 값

```javascript
let name = "캠프"; // (문자열)
let number = 3; // (숫자열) ""를 쓰지 않아야 숫자
let fool = true; // ""를 쓰지 않아야 boolean
```

> **참조타입(Reference type)** : 나머지 모든 타입, 참조타입 = 객체타입, 가변성의 특징을 가짐

## [데이터 타입 확인 및 변경]

- `typeof` 명령을 이용하여 자료형을 확인

```javascript
typeof "name"; // "string"을 반환
typeof "nubmer"; // "number"을 반환
typeof "fool"; // "boolean"을 반환
```

- 데이터 타입 변경 가능

```javascript
Number("35"); // 문자 35를 숫자 35로 변경
String(24); // 숫자 24를 문자 "24"로 변경
String(true); // 불린 true를 문자 "true"로 변경
```

# #연산자

## 1. 산술연산자

> 산술연산자는 **더하기(+) , 빼기(-), 곱하기(\*), 나누기(/), 나머지(%)**와 같은 연산을 하는 기호를 의미

### ❗️ 문자타입의 연산

- 숫자 타입의 연산과 문자 타입의 연산 결과는 완전히 다름

```javascript
//숫자 타입 연산
89 + 54;
// 결과 : 140

// 문자 타입 연산
"89" + "54";
// 결과 : "8954"
```

- 숫자와 문자의 연산 결과는 문자열로 계산됨(`+`)
  - 다른 `-`, `*` 연산은 어느정도 유연성으로 숫자로 계산됨

### 💡 실무 예시

#### 1. 나머지(%) 연산자 사용

- 게시판의 게시물에서 각 줄을 **홀/짝으로 구분**하고 색을 다르게 할 때 사용

## 2. 비교연산자

> 비교연산자는 좌우의 두 값을 비교해야 할 때 사용하는 연산자이며, Boolean을 반환

- `===` : 같다
- `!==` : 같지 않다
- `<=` : 작거나 같다
- `>=` : 크거나 같다
- `>` : 크다
- `<` : 작다

- 등호의 순서는 중요함

### ❗️ 엄격한 동치연산자

- `==`, `!=`는 타입은 무시한채 값만 비교함(느슨한 동치연산자 - 실무 사용 X)
- `===`, `!==`는 데이터 타입과 값까지 같아야 `True`
- ⭐️ 실무에서는 엄격한 비교연산자만을 사용

## 3. 논리연산자

> 논리연산자는 **그리고(&&), 또는(||), 부정(!)**을 나타내는 기호를 의미

- `&&` : 양쪽이 모두 True여야 True를 반환
- `||` : 한쪽만 True여도 True를 반환
- `!` : Boolean을 반전시킴

# #조건문

<!-- precamp/class/03-javascript/연습-05-variable-if.js 참고 -->
<!-- CSS-JS/class-js/section02/02-02/01-if-and-switch.html 참고 -->

> **조건문** : 작성한 조건이 참일 경우 지정한 코드를 수행하도록 하는 기능

## [if…else]

- **핵심** : 시작점과 끝점이 존재
- 비교 연산자와 함께 쓰임
- 조건이 맞다면 `A` 실행, 아니라면 `B` 실행

```javascript
if(조건) {
  A 실행
} else {
  B 실행
}
```

- 조건1이 맞다면 `A` 실행, 아니면 조건2가 맞다면 `B` 실행, 아니면 조건3이 맞다면 `C` 실행, 모두 아니면 `D` 실행
- 조건문 개수 제한은 없음

```javascript
if(조건1) {
  A 실행
} else if(조건2) {
  B 실행
} else if(조건3) {
  C 실행
} else {
  D 실행
}
```

### 삼항연산자(초간단 조건문)

```javascript
const 상자 = 1 + 1 === 2 ? "500원" : "0원";
```

## [switch문]

- 변수의 값을 평가하여 여러 경우 중 하나에 해당하는 코드 실행
- 특정 변수의 값에 따라 여러 분기 처리를 할 때 사용, 가독성이 좋고, 많은 경우를 처리할 때 사용
- `break문`을 이용해서 각 케이스의 종료를 명시적으로 관리
- ❗️ 일치하는 것이 없다면, default 값 실행
- ❗️ 일치하는 것이 있다면, 아래 코드들이 다 실행됨 -> `break` 필수!

```javascript
switch (변수) {
  case 조건1:
    // 조건1이 참이면 실행할 코드
    break;
  case 조건2:
    // 조건2이 참이면 실행할 코드
    break;
  default:
  // 어떤 값도 해당하지 않을 때 실행할 코드
}
```

### 💡 실무 예시

#### 1. if문 언제 사용하는지

- 회원가입 시, `비밀번호 === 비밀번호확인`이 같은지 체크할 때 주로 사용

```javascript
const password1 = "입력받은 비밀번호"; // 사용자가 입력한 비밀번호를 변수에 저장
const password2 = "입력받은 비밀번호확인"; // 사용자가 입력한 비밀번호확인을 변수에 저장

if (password1 === password2) {
  alert("회원가입을 축하합니다.");
} else {
  alert("비밀번호가 다릅니다. 다시 한번 확인해 주세요.");
}
```

# #반복문

<!-- precamp/class/03-javascript/연습-06-for.js 참고 -->

> 같은 행위를 반복하는 것

- **핵심** : 몇 번 반복할 것인가

## [For문 작성 방법]

```javascript
for (초기식; 조건식; 증감문) {
  반복해서 실행할 내용
}

for (let i=0; i<5; i=i+1) {
  console.log("hello")
}
```

- 초기식 : 변수의 선언 `let 변수 = 0`
- 조건식 : 반복할 조건
- 증감식 : 변수의 증가 또는 감소 식 `i++`/`i--`

❗️ 특정 조건 만족 시,  
조건식을 통한 정상 종료 이전에도 `종료(break)` 가능  
명령문을 실행하지 않고 다음 반복으로 `건너뛰기(continue)` 가능

### 💡 실무 예시

#### 1. for문 언제 사용하는지

- 동일한 형태의 게시물이나 글, 그림 등을 **반복적으로 보여줄때** 주로 사용
- 예를 들어 **실시간 검색어** 같이 반복되는 컨텐츠를 보여줄 경우

## [MAP]

> **map** : 배열 객체의 메서드, 배열의 각 요소에 주어진 함수를 호출하여 새로운 배열을 생성

```javascript
const 친구들 = ["철수", "영희", "훈이"];
const 우리반 = 친구들.map((친구) => 친구 + "어린이");
// ["철수어린이", "영희어린이", "훈이어린이"]

/* 화살표 함수 -> 중괄호 생략 버전 */
const 우리반 = 친구들.map((친구) => {
  return 친구 + "어린이";
}); // 상황에 따라 생략 가능, return 값만 존재할 경우
```

# #수학 객체

<!-- precamp/class/03-javascript/연습-07-math.js 참고 -->

> 자바스크립트의 **수학 기능**을 사용하는 명령어

## [수학 객체의 종료]

### 1. 최대값, 최소값 구하기

```javascript
// 최대값, 최소값
Math.max(4, 29, 1, 12); // 29
Math.min(4, 29, 1, 12); // 1
```

### 2. 반올림, 올림, 버림

```javascript
Math.round(2.712); // 3
Math.ceil(4.1); // 5
Math.floor(12.8); // 12
```

### 3. 랜덤 수 생성

```javascript
Math.random(); // 0.822...(0 ~ 1 까지의 임의의 수)
```

### 4. 루트

```javascript
Math.sqrt(2); // 1.414...
```

#### 1. Math.random() 언제 사용하는지

- **휴대폰 인증번호** 등의 랜덤 숫자를 만들어 낼 때 사용
