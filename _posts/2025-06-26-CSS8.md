## 달력

### 커스텀 달력

#### 1. 클릭영역

<!-- CSS-JS/class-css/section08/08-01/01-calendar-click-area.html 참고 -->

<abbr title="indicator">**-webkit-calendar-picker-indicator** : 웹킷 기반 브라우저에서 날짜 입력 필드의 캘린더 아이콘에 대한 스타일을 정의하는 가상 선택자</abbr>

기본 캘린더 아이콘의 위치, 크기, 배경 등을 지정 가능

```css
.CSS_달력 {
  position: relative;
}
.CSS_달력::-webkit-calendar-picker-indicator {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  background: transparent;
}
```

#### 2. 플레이스 홀더

<!-- CSS-JS/class-css/section08/08-01/02-caledar-placholder1.html 참고 -->

- `-webkit-datetime-edit-text` : 날짜 입력 필드의 텍스트 부분 스타일링
- `-webkit-datetime-edit-year-field` : 날짜 입력 필드에서의 연도 스타일링
- `-webkit-datetime-edit-month-field` : 날짜 입력 필드에서 월 스타일링
- `-webkit-datetime-edit-day-field` : 날짜 입력 필드에서 일 스타일링

```css
.CSS_달력::-webkit-datetime-edit-text,
::-webkit-datetime-edit-year-field,
::-webkit-datetime-edit-month-field,
::-webkit-datetime-edit-day-field {
  display: none;
}
.CSS_달력::after {
  content: "생일을 선택하세요.";
  position: absolute;
  top: 0;
  left: 0;
}
```

<!-- CSS-JS/class-css/section08/08-01/02-caledar-placholder2-with-attr.html 참고 -->

<abbr title="attr">**attr** : 태그에 달린 속성 가져오는 CSS 기능</abbr>

```html
<div data-title="Hello World" class="example">Example</div>
```

```css
.example::after {
  content: attr(data-title);
} /* example 요소 뒤에 "Hello World" 라는 텍스트가 추가됩니다. */
```

💡 <mark>attr() 함수는 주로 ::before 및 ::after 가상 요소에서 사용, 요소의 특정 속성 값을 기반으로 콘텐츠를 동적으로 생성하는데 유용함</mark>

#### 3. 선택과 검증

<!-- CSS-JS/class-css/section08/08-01/03-calendar-selection-with-validation.html 참고 -->

- `:valid` : 입력값이 유효할 때 적용, 사용자가 올바른 값을 입력했을 때 특정 스타일을 적용하고, 필요한 경우 사용자에게 피드백을 제공하는데 사용
- `:invalid` : 입력값이 유효하지 않을 때 적용, 사용자가 올바르지 않은 값을 입력했을 때 특정 스타일을 적용하고, 오류 메세지나 시각적 피드백을 제공하는 데 사용

```css
.CSS_달력:valid::-webkit-datetime-edit-text,
:valid::-webkit-datetime-edit-year-field,
:valid::-webkit-datetime-edit-month-field,
:valid::-webkit-datetime-edit-day-field {
  display: inline; /* 바닥에 숨겨져있는 선택된날짜(연도.월.일.) 숨김 취소하자! */
  color: blue;
}
.CSS_달력:valid::after {
  display: none; /* 위에 덮여져 있는 플레이스홀더(.CSS_달력::after) 숨기자! */
}
.CSS_달력:invalid::after {
  color: red;
}
```

## 그라데이션

### 선형 그라데이션

<!-- CSS-JS/class-css/section08/08-02/01-linear-gradient.html 참고 -->

<abbr title="gradient">**선형 그라데이션** : 색상이 한 방향으로 점진적으로 변하는 효과를 생성하는 CSS 속성</abbr>

- 기본적으로 상단에서 하단으로 진행
- 첫 번째 색상에서 두 번째 색상으로 부드럽게 변함

```css
.CSS_상자1 {
  width: 300px;
  height: 300px;

  /* 1. 수직방향(0도)으로 빨강부터 파랑까지 */
  background: linear-gradient(0deg, red, blue);

  /* 2. 45도 방향으로 핑크부터 퍼플까지 */
  background: linear-gradient(45deg, pink, purple);

  /* 3. 30%까지 핑크, 30% ~ 100%까지 퍼플 그려줘! */
  background: linear-gradient(45deg, pink 30%, purple 30% 100%);

  /* 4. 핑크, 퍼플 30%부터 그려줘! */
  background: linear-gradient(45deg, pink, purple 30%);
}
```
