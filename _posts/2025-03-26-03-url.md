# #주소창 개념

## [URI]

> **URI(Uniform Resource Identifier)** : 웹에서 자원을 식별하는 데 사용되는 문자열의 집합

**URL과 URN을 포함하는 상위 개념**

- 프로토콜 : 자원에 접근하는 방법(예: `http, https, ftp`)
- 호스트 : 자원이 있는 서버의 주소(예: `www.example.com`)
- 경로 : 서버 내에서 자원의 위치(예: `/path/to/resource`)
- 쿼리 문자열 : 추가 매개변수(예: `?key=value`)
- 앵커 또는 프래그먼트 : 문서 내 특정 위치(예: `#section1`)

## [URL]

> **URL(Uniform Resource Locator)** : 자원의 위치를 지정하는 URI, 웹 주소

## [URN]

> **URN(Uniform Resource Name)** : 자원의 이름을 지정하는 URI, 자원의 위치와는 무관하게 자원을 고유하게 식별하는 데 사용
