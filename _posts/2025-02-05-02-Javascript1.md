# #변수와 상수

<!-- precamp/class/03-javascript/01-variable.js 참고 -->
<!-- CSS-JS/class-js/section01/01-01/01-data.html 참고 -->

- 변수 : 어떤 관계나 범위 안에서 여러가지 값으로 변할 수 있는 수
  - `var`, `let` (var는 옛날 방식으로 사용하지 않음)
- 상수 : 변하지 아니하는 일정한 값을 가진 수나 양
  - `const`

## [변수와 상수 만들기]

### 1. 선언(declaration)

- 변수의 이름을 알려주는 행위

```javascript
let apple;
```

### 2. 할당(definition)

- 변수에 데이터를 담아주는 행위

```javascript
apple = "맛있는 사과";
```

### ⭐️ 선언과 할당을 한번에

```javascript
let apple = "맛있는 사과";
```

## [변수와 상수의 종류와 특징]

|                         | `var` | `let` | `const` |
| :---------------------: | :---: | :---: | :-----: |
|  이름 중복<br>(재선언)  |   O   |   X   |    X    |
| 데이터 수정<br>(재할당) |   O   |   O   |    X    |

```javascript
// 상수 변경하기(예제)
const classmate1 = "철수";
classmate1 = "민수"; // 에러!!  (다시 담기 불가능)

// 변수 변경하기(예제)
let classmate2 = "훈이";
classmate2 = "민수"; // 성공!!  (다시 담기 가능)

// 변수 변경하기(예제)
let classmate3; // 처음에 빈 상자로 둘 수도 있음
classmate3 = "짱구"; // 성공!!
```

## [변수와 상수의 작명 규칙]

- `camelCase` : let myMoney -> js
- `snake_case` : my_money -> python

## 객체란?

> 객체는 다양한 데이터를 하나의 그룹으로 묶는 보따리와 같음  
> 다양한 데이터를 하나로 묶기 위해서, 각각의 데이터를 키와 값으로 연결

- `{}`중괄호 안에 데이터를 넣고 `,`로 각 데이터를 구분

```javascript
const profile = {
  name: "홍길동",
  age: 50,
  height: 165,
};
```

- `value`값은 비어있을 수 있으나, `key`는 비어있을 수 없음
- 빈 객체, 숫자 값, 문자열 값 넣을 수 있음
- 키에는 따옴표를 적지 않음

### [객체에 담긴 값(Value)을 가져오는 방법]

- 변수명.KEY -> `profile.name`
- 변수명["KEY"] -> `profile["school"]`

## [객체와 배열 함께 쓰기]

```javascript
// 객체들을 배열에 담아서 선언하기
const classmates = [
  {
    name: "철수", // 1번째 객체
    age: 8,
    school: "다람쥐초등학교",
  },
  {
    name: "영희", // 2번째 객체
    age: 8,
    school: "다람쥐초등학교",
  },
  {
    name: "훈이", // 3번째 객체
    age: 7,
    school: "토끼초등학교",
  },
];

// 위 객체들을 깔끔하게 한줄로 적기
const classmates = [
  { name: "철수", age: 8, school: "다람쥐초등학교" },
  { name: "영희", age: 8, school: "다람쥐초등학교" },
  { name: "훈이", age: 7, school: "토끼초등학교" },
];

// 배열안의 객체에서 뽑아내기
classmates[0].name; // 철수
classmates[0].age; // 8
classmates[0].school; // 다람쥐초등학교
```

- 예를 들어 **실시간 검색어와 같은 창 띄울 때 사용**

# #배열

<!-- precamp/class/03-javascript/연습-01-array.js 참고 -->

## 배열이란?

> 여러개의 데이터를 한번에 담을 수 있음

- 대괄호 [ ] 안에 데이터를 쉼표 , 로 각 데이터를 구분

## [배열에 데이터 담아보기]

```javascript
// 빈 배열
const blanksArr = []; // 아무것도 안담는 것도 가능

// 숫자들로 이루어진 배열
const numbers = [2, 10, 7, 3.3]; // 숫자 담기

// 문자들로 이루어진 배열
const classmates = ["코드", "캠프"]; // 문자 담기
```

## [배열 특징(index)]

- `index` : 배열에 있는 각 데이터의 위치  
  ❗️ (주의) **index는 0부터 시작**, 배열은 1부터 시작하지 않고, 0부터 시작한다는 것에 주의 ❗️
- `length` : 배열의 길이, index와 다르게 1부터 시작

## [배열의 메서드와 속성]

- 일종의 기능일 경우 메서드 뒤에 소괄호()가 붙음  
  📌 [배열의 메서드](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array#%EC%A0%95%EC%A0%81_%EB%A9%94%EC%84%9C%EB%93%9C) 참고

```javascript
// 배열 만들기
const blanks = []; // 비어있는 배열
const numbers = [2, 10, 7, 3.3]; // 숫자들로 이루어진 배열
const classmates = ["철수", "영희", "훈이"]; // 문자들로 이루어진 배열

// 배열의 길이 구하기 _ length
classmates.length; // 3

// 배열의 값 꺼내기
classmates[0]; // "철수"
classmates[1]; // "영희"
```

- `array.push(추가할 데이터)` : 배열의 가장 뒤의 데이터를 추가
- `array.pop()` : 배열의 가장 뒤의 데이터를 삭제
- `array.includes(검색 데이터)` : 특정 배열에 주어진 데이터가 포함되어있는지 확인(Boolean값 반환)
- `array.indexOf(검색 데이터)` : 특정 배열에서 지정된 요소를 찾을 수 있는 첫 번째 인덱스를 반환, 찾을 수 없으면 -1 반환

# #문자열

<!-- precamp/class/03-javascript/연습-02-email-split.js 참고 -->

- 문자열도 배열과 같이 메서드를 이용할 수 있고, `index`를 이용해 요소를 가지고 올 수 있음

## [문자열의 메서드와 속성]

```javascript
// 문자열(배열)
const classmates1 = "철수";
classmates1[0]; // "철"
classmates1[1]; // "수"

// 문자열 쪼개기
const classmates2 = "철수&영희";

// 문자열 양쪽 공백 제거하기
const classmates3 = " 철수 & Milk ";
classmates3.trim(); // "철수 & Milk"

// 문자열 대소문자 변환하기
classmates3.toUpperCase(); // "철수 & MILK"
classmates3.toLowerCase(); // "철수 & milk"

// 문자열에 빈칸 채우기
const chulsooNumber = "1234";
chulsooNumber.padStart(10, "0"); // "0000001234"
chulsooNumber.padEnd(10, "0"); // "1234000000"
```

## [변수와 문자열의 조립]

```javascript
const name = "철수";
const age = 8;
const school = "다람쥐초등학교";

console.log(name + "는 " + age + "살 이고, " + school + "에 다닙니다.");
```

- 위 방식은 가독성이 저하되고, 유지보수가 어려워 아래 방식인 **템플릿 리터럴** 선호

```javascript
const name = "철수";
const age = 8;
const school = "다람쥐초등학교";

// 템플릿 리터럴
console.log(`${name}는 ${age}살 이고, ${school}에 다닙니다.`);

// 템플릿 리터럴 여러줄 응용
console.log(`
	안녕하세요!
	철수는 ${age}살 입니다.
	그리고 ${school}에 다닙니다.
`);
```

- `${}`를 통해 변수를 직접 삽입

#### 2. toUpperCase, toLowerCase 기능

- 사용자가 검색 기능을 사용할 때 문자열의 `toUpperCase, toLowerCase` 사용
- 컴퓨터에 저장된 단어, 내가 찾을 단어를 모두 소문자 또는 대문자로 변경하고 찾아냄

# #함수

<!-- CSS-JS/class-js/section01/01-01/03-function1.html 참고 -->

> **함수**란 어떤 **기능을 수행** 하거나 계산을 수행할 수 있도록 하는 도구

```javascript
function hello() {
  alert("안녕하세요");
}

function 함수이름(매개변수) {
  함수를 호출했을 때 실행할 명령문
  (데이터 반환 : Optional)
} /* 함수 안에 데이터 제공이 필요할 때 매개변수를 넣어 줌 */
```

- **매개변수(Parameter)** : 함수에 외부에서 값을 전달하여 작업을 수행할 수 있게 해주는 중요한 요소

<!-- CSS-JS/class-js/section01/01-01/04-function2-with-scope-chain.html 참고 -->

## [스코프]

> 프로그래밍 언어에서 변수가 사용될 수 있는 범위를 나타내는 개념

```javascript
/* 전역 스코프 공간 */
let x = 0;

const scopeTest = function () {
  let y = 1;
  console.log(x);
}; /* 지역 스코프 공간 */

console.log(x); // 지역 스코프에서 참조 가능
console.log(y); // 전역 스코프에서 참조 불가
```

```javascript
function 바깥에함수() {
  const 바나나 = 10;
  console.log(바나나); // 10

  function 안쪽에함수() {
    const 바나나 = 50; /* 스코프가 달라 똑같은 변수명 선언 가능 */
    console.log(바나나); // 50
    /* 만약 위에 새로 선언 없이 바나나를 찾을 경우 계속해서 상위 '바나나' 변수명을 찾아 값을 부여 - 스코프 체이닝 */
  }

  console.log(바나나); // 10
}
```

## [함수의 리턴]

- `return` : 바로 뒤에 오는 데이터를 함수를 호출했던 위치로 전달(함수 종료 - return 아래 코드는 실행 안됨)

## [함수 작성 방법]

### 1. 함수 선언식

```javascript
function hello(name) {
  alert(name + "님 안녕하세요");
} /* 호이스팅 문제로 인해 표현식 등장 */
```

### 2. 함수 표현식

```javascript
const hello = function (name) {
  alert(name + "님 안녕하세요");
}; // 익명함수
```

### 3. 화살표 함수

```javascript
const hello = (name) => {
  alert(name + "님 안녕하세요");
}; /* 표현식 간소화 */
```

⭐️ 함수 선언식 -> 화살표 함수로 변환하는게 어려움(실무에서는 화살표 함수 많이 사용)  
⭐️ 함수 실행 방법은 모두 동일

❗️ 매개변수(parameter)와 `return` 값은 필수가 아님

- 매개변수와 리턴값은 있어도 되고 없어도 되는 값이기 때문에 반드시 적어주실 필요는 없음, 상황에 따라 사용

#### 1. 함수 언제 사용하는지

- 특정 기능이 필요하다 할 때마다 만들어서 사용

# #호이스팅

<!-- CSS-JS/class-js/section01/01-02/01-hoisting.html 참고 -->

> 함수, 변수의 선언이 마치 위로 끌어올려진 것처럼 동작하는 것

- 예시) 함수를 윗 줄에 실행 후 아래줄에 만들어도 실행이 됨
- `JavaScript`는 코드를 실행하기 전에 먼저 선언된 변수, 함수 등을 전역 환경에 담아두게 됨, 이후에 정리된 코드 실행

<!-- CSS-JS/class-js/section01/01-02/02-hoisting-and-tdz.html 참고 -->

## ⭐️ 호이스팅 문제

```javascript
console.log(결제금액 + 1000); // NaN
var 결제금액 = 5000;
```

- `var` 사용 시 호이스팅으로 인해 선언은 되는데 할당은 되지 않아 값이 이상하게 나옴
- 차라리 에러가 나는게 나은 상황

- **해결** : `let, const`의 경우 호이스팅되었을 때 에러가 나서 실행이 되지 않음(`TDZ(Temporal Dead Zone)`)

## ⭐️ 중복선언 문제

```javascript
function 결제금액조회() {
  console.log(2000);
}

function 결제금액조회() {
  console.log(10000);
}

결제금액조회(); // 10000
/* 실수로 2개를 선언했을 때 뒤 함수로 덮어쓰여져서 결과값이 달라짐 */
```

- **해결** : 함수표현식, 화살표함수로 사용(가급적 화살표함수 추천)

# #DOM

<!-- precamp/class/03-javascript/04-document.js 참고 -->
<!-- CSS-JS/class-js/section01/01-02/03-dom1.html 참고 -->

> **Document Object Model** : 웹브라우저가 정적인 웹페이지를 변경하거나 조작하기 위해 `HTML` 파일을 자바스크립트 객체로 만들어 줌

- `HTML`과 자바스크립트가 서로 상호작용하여 동적인 페이지 제작 가능

## [DOM 트리]

- `Document` : **문서(document) 노드**, DOM에 진입할 수 있는 진입점 역할
- `HTML` : Document를 제외하고 최상위에 위치, 이러한 노드를 **루트(root) 노드**라고 함, 루트 노드는 항상 하나만 존재
- **요소(element) 노드** : 속성 노드를 가질 수 있는 유일한 node / 예) `head, body, title, div ...`
- **속성(attribute) 노드** : 요소 노드에 관한 별도의 정보를 담고 있지만, 해당 요소 노드의 child node에는 속하지 않음 / 예) `src=”…”, id=”…”`
- **텍스트(text) 노드** : 텍스트 노드는 child node, 자식 노드를 가질 수 없기 때문에 항상 leaf node
- `Parent Node` : 각 node의 바로 위에 위치한 Node를 Parent Node, 부모 노드
- `Child Node` : 각 node의 바로 아래에 위치한 Node를 Child Node, 자식 노드
- `Leaf Node` : 트리구조 내에서 가장 끝단에 위치한, Child Node가 없는 Node

## [DOM 메서드]

- `document.getElementById()` : Element Node의 id 속성을 체크해서 해당하는 Element를 참조
- `document.getElementByClass()` : Element Node의 class 속성을 체크해서 해당하는 Element를 참조
- `document.querySelector()` : 소괄호 안에 입력한 값에 해당하는 Element를 참조해온다. id(”#”)를 입력하는 경우 id를 기반으로, class(”.”)를 입력하는 경우 class를 기반으로 참조
- `document.querySelectorAll()` : 소괄호 안에 입력한 값에 해당하는 Element를 참조, querySelector와 다르게 배열 형태로 모든 요소를 참조
- `document.createElement()` : 새로운 Node를 생성, Node의 형태는 생성되지만 DOM에 직접 추가해주는 과정을 거치치 않으면 DOM에 속하지 않음
- `document.appendChild()` : Element Node를 현재 DOM에 추가, 이때의 document는 다른 Element가 될 수도 있음

## [Event]

> **DOM** 내에서 발생하는 이벤트를 의미

- **이벤트** : 키보드 버튼을 누르거나 마우스를 클릭 하는 등, 사용자의 액션

## ❗️ 호이스팅 문제

```html
<html>
  <head>
    <script>
      document.getElementById("나의태그").innerText = "철수";
    </script>
```
