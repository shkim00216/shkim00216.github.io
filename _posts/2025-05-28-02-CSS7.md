# #이미지 맞춤과 비율

## [object-fit]

<!-- CSS-JS/class-css/section06/06-01/01-object-fit.html 참고 -->

> **이미지 맞춤 변경(object-fit)** : 이미지나 동영상 같은 요소를 부모 요소 안에 어떻게 맞출지를 결정하는 속성, 다양한 크기의 이미지를 고정된 크기의 박스에 넣을 때 유용

- `contain` : 긴부분 끼워넣기
- `cover` : 긴부분 잘라내기, 많이 쓰임

- `fill` : 부모 요소의 크기에 맞도록 콘텐츠가 늘어나거나 축소됨, 비율이 유지되지 않아 왜곡될 수 있음
- `none` : 콘텐츠가 원래 크기를 유지함
- `scale-down`: 콘텐츠가 원래 크기와 `contain` 크기 중 더 작은 크기로 조정됨

### 💡 대부분의 웹사이트에서는 object-fit: cover 사용

- 일관된 레이아웃과 유연한 반응형 디자인이 가능함

## [aspect-ratio]

<!-- CSS-JS/class-css/section06/06-01/02-aspect-ratio.html 참고 -->

> **aspect-ratio** : 요소의 너비와 높이의 비율을 설정하는 데 사용

```css
aspect-ratio: 1/3; /* 가로1 : 세로3 */
aspect-ratio: 2/1; /* 가로2 : 세로1 */
aspect-ratio: 2/1; /* 가로2 : 세로1 */
/* 너비 / 높이 */
```

## [animationend 이벤트]

<!-- CSS-JS/class-css/section06/06-02/02-page-effet1-back.html, 02-page-effet2-back-detail.html 참고 -->

> **animationend 이벤트** : CSS 애니메이션이 완료될 때 발생, 애니메이션이 끝난 후 특정 작업 수행 가능

- 애니메이션이 끝나는 정확한 시점 감지 가능
- 화면에서 요소가 사라진 후 페이지 이동, 요소가 변환된 후 데이터 로드 등 다양한 작업을 이벤트와 결합하여 수행 가능

```javascript
const JS_나가기기능 = () => {
  document.getElementById("HTML_페이지").style =
    "animation-name: 이전페이지애니메이션;";

  this.addEventListener("animationend", () => {
    location.href = "./02-page-back-effect1.html";
  });
};
```

## [View Transition API]

<!-- CSS-JS/class-css/section06/06-02/03-view-transition1.html, 03-view-transition2-detail.html 참고 -->

> **View Transition API** : 페이지 전환, 화면 전환 또는 콘텐츠 변경 시 부드럽고 자연스러운 애니메이션을 제공하기 위해 사용되는 최신 웹 기술

### 1. @view-transition

- `View Transition API`의 설정을 정의하는 `CSS` 규칙
- 페이지 전환 시 애니메이션 동작을 자동으로 적용할지 여부 등을 지정

```css
@view-transition {
  navigation: auto; /* 페이지 간의 내비게이션 전환에 대해 자동으로 애니메이션을 적용 */
}
```

### 2. ::view-transition-group(root)

- 전체 전환 그룹을 정의하는 데 사용
- 전환 애니메이션의 타이밍, 지속 시간 등을 제어

```css
::view-transition-group(root) {
  animation-duration: 0.5s; /* 페이지 전환 애니메이션이 0.5초 동안 재생되도록 설정 */
}
```

### 3. ::view-transition-old(root)와 ::view-transition-new(root)

- `::view-transition-old(root)` : 전환 전의 페이지를 대상으로 하는 애니메이션을 정의
- `::view-transition-new(root)` : 전환 후의 페이지를 대상으로 하는 애니메이션을 정의

```css
::view-transition-old(root) {
  animation-name: 이전페이지애니메이션;
  animation-duration: 0.4s;
}

::view-transition-new(root) {
  animation-name: 다음페이지애니메이션;
  animation-duration: 0.4s;
}
```

#### ❗️ View Transitions API는 아직 실험적 API라 MDN 기준 Chrome(111), Edge(111), Chrome Android(111) 최신(23.04.03 기준) 브라우저만 지원되고 있음
