## 심화 UI

### accent 색 변경

<!-- CSS-JS/class-css/section07/07-01/01-accent-color.html 참고 -->

<abbr title="accent">**accent-color** : UI요소의 강조 색상을 설정할 수 있음</abbr>

#### 색상 표시 방법

1. 색상 이름 표기법
    1. 웹 안전 색상이라고 불리는 216가지 색상을 이름으로 표기
    2. 📌 [웹 색상](https://ko.wikipedia.org/wiki/%EC%9B%B9_%EC%83%89%EC%83%81)
    ```css
    color: red;
    ```
2. `Hex` 색상코드
    1. 색상을 16진수 여섯자리로 색상을 표기
    ```css
    color: #94fb11;0
    ```
3. `rgb` 색상코드
    1. `rgb(red좌표, green좌표, blue좌표)` 값을 이용해 색상을 표기
    ```css
    color: rgb(251, 241, 17);
    rgba(0, 0, 0, 0.5) /* 투명도 적용 */
    ```

### 커스텀 토글

<!-- CSS-JS/class-css/section07/07-01/02-toggle.html 참고 -->

<abbr title="toggle">**토글** : 꺼짐과 켜짐을 제어하는 스위치</abbr>

#### 1. 가상클래스 선택자

`hover` : 사용자가 마우스를 특정 요소 위에 올렸을 때 적용되는 스타일을 정의(버튼, 링크 같은 요소에 주로 사용)

```css
button:hover {
  background-color: lightblue; // 마우스 올렸을 때 배경색이 변경
}
```

`active` : 사용자가 요소를 클릭하고 있는 동안 적용되는 스타일 정의

```css
button:active {
  transform: scale(0.95); // 마우스 클릭했을때 약간 작아짐
}
```

`focus` : 요소가 포커스 된 상태일 때 적용하는 스타일 정의, 주로 키보드나 마우스를 통해 사용자가 요소를 선택할 때 사용

```css
input:focus {
  border: 2px solid blue; /* 입력 필드에 포커스가 갔을 때 테두리 색상 변경 */
}
```

`checked` : 체크박스나 라디오 버튼 같이 선택 가능한 요소가 선택 되었을 때 적용되는 스타일 정의

```css
input[type="checkbox"]:checked {
  background-color: green; /* 체크박스가 선택되었을 때 배경색 변경*/
}
```

#### 2. 가상요소 선택자

<abbr title="after">**가상요소 선택자** : 선택된 요소 주변을 변경하는 선택자</abbr>

`::after` : 선택한 요소의 컨텐츠 뒤에 가상의 컨텐츠를 추가 하는데 사용, 장식적 요소나 추가적인 정보를 삽입

```css
h2::after {
  content: " ✔"; /* 체크 표시를 추가 */
  color: green; /* 체크 표시의 색상 */
}
```

`::before` : 선택한 요소의 컨텐츠 앞에 가상의 컨텐츠를 추가하는데 사용, 아이콘/장식/텍스트 등을 추가하여 요소를 꾸미거나 강조하는데 사용

  ```css
  h1::before {
    content: "★ "; /* 별표를 추가 */
    color: gold; /* 별표 색상 설정 */
  }
  ```

💡 <mark>가상클래스 선택자와 가상요소 선택자 동시 사용 가능!</mark>

### 커스텀 드롭다운

<!-- CSS-JS/class-css/section07/07-01/03-dropdown.html 참고 -->

<abbr title="dropdown">**드롭다운** : 내가 만드는 예쁜 선택박스</abbr>

<abbr title="span">**결합자** : 두 개를 결합</abbr>

1. 자식 결합자
    1. `div` 자식인 `span`만 가져와
    ```css
    div > span {
      color: red;
    }
    ```
2. 자손 결합자
    1. `div` 아래의 `span` 모두 가져와
    ```css
    div span {
      color: orange;
    }
    ```
3. 인접 형제 결합자
    1. 바로 아래의 형제 갖고 와
    ```css
    div + span {
      color: blue;
    }
    ```

<abbr title="css">**CSS 변수** : CSS에서 사용되는 변수</abbr>

```css
:root {
  --기본글자색: black;
  --기본배경색: white;
  --기본체크색: red;
  --인풋배경색: lightgray;
  --인풋플레이스홀더색: gray;
  --버튼글자색: black;
  --버튼배경색: lightgray;
}

body {
  color: var(--기본글자색);
  background-color: var(--기본배경색);
  accent-color: var(--기본체크색);
}
```

## 다크모드

<!-- CSS-JS/class-css/section07/07-02/01-dark.html, 02-dark-input.html 참고 -->

> **다크모드** : 기본적으로 밝은 색상을 어두운 색상으로 변경하여, 사용자가 눈의 피로를 덜 느끼도록 도움

```javascript
const JS_다크모드기능 = () => {
  document.body.classList.toggle("CSS_불꺼진방");
};
```

### CSS 전역변수

<!-- CSS-JS/class-css/section07/07-02/03-global-var.html 참고 -->

<abbr title="globalVar">**CSS 전역변수** : 모든 태그에서 사용 가능한 CSS 변수</abbr>

#### :root 선택자

- `:root` 선택자는 문서 트리의 최상위 요소를 선택
- `CSS` 전역변수로 **다크모드 유지보수성**을 높일 수 있음

```css
/* 불켜진방 */
:root {
  --기본글자색: black;
  --기본배경색: white;
  --기본체크색: red;
  --인풋배경색: white;
  --인풋플레이스홀더색: gray;
  --버튼글자색: black;
  --버튼배경색: lightgray;
}

/* 불꺼진방 */
.CSS_불꺼진방 {
  --기본글자색: white;
  --기본배경색: black;
  --기본체크색: orange;
  --인풋배경색: gray;
  --인풋플레이스홀더색: orange;
  --버튼글자색: blue;
  --버튼배경색: aqua;
}
```
